# 战术战斗结算 (Combat Resolution)

> 蓝图 §九、§十七。原型战术核心。结算做成**纯函数**(战场状态 → 战斗结果),见 csharp skill §3。

## 损耗公式 (抽象 attrition)
```
损耗 = f( 兵种克制
        × 地形
        × 士气
        × 体力
        × 随机 )        # 随机走注入的 IRandomSource
```
不做逐兵模拟,只算部队级 attrition(兵力 / 士气 / 体力的增减)。

## 兵种克制三角 (`Arm`)
- **枪克骑** Spear > Cavalry
- **骑克弓散** Cavalry > Bow(尤其散阵)
- **弓克步** Bow > 步兵
- **盾抗远程** Shield 抗远程伤害

> 具体克制系数蓄意留白,留到原型期平衡(蓝图 §六)。给值时标"建议起始,待调"。

## 隐藏关键值 (不直接示数,靠表现暗示)
- **士气 `Morale`**:崩则**溃逃**(部队失控 / 逃散)。
- **体力 `Stamina`**:竭则**战力打折**。
- 二者是隐藏值:玩家从战报的措辞 / 表现推断,而非看到精确数字 —— 与迷雾母题一致。

## 副将解读 = 第二层迷雾
同一个意图(动词 + 基调),不同性格副将执行不同。原型只做轻量:性格影响激进 / 谨慎 + 情况变化时临机改判。完整养成见蓝图 §十(熟悉度降低迷雾、将领之痛)。

## 战报产生时机
事件驱动(接敌 / 受创 / 溃败 / 抵达 / 发现敌军)+ 低频定期 + 玩家主动派传令兵索要。战报经传令兵延迟送回,途中可被拦截 → 丢失(走情报管线)。

## 时间与暂停
实时可暂停。暂停可读情报 / 思考,**下命令受限**(避免暂停变作弊键,见 intel-pipeline 等待期语义)。

## 胜负判定
- **胜**:敌主力被歼 / 溃 / 撤。
- **败**:我方主力崩溃。
- 局时长 20–30 分钟,靠**地图大小 + 行军速度**调,不靠硬计时。

## 地形 / 天气的战斗侧作用 (信息侧见 intel-pipeline)
- 地形(山地 / 林地 / 河流 / 隘口 / 平原 / 城墙):改移动速度、兵种效能(骑忌林 / 城)。
- 天气(晴 / 雨 / 雾 / 雪 / 夜):改行军、弓弩效能、士气。
- 原型子集:平原 / 林地 / 河流 + 晴 / 雾 / 夜。天气由章节 / 难度设定,**不在局内随机变**。

## 敌方 AI (战术层)
基于敌方自己的**认知世界**(对称迷雾)用 **Utility AI** 决策:候选行动按"敌方认知下的收益"打分选最高。性格 = 效用权重向量(激进 / 谨慎 / 善诈 / 稳健 = 不同权重),改权重即改性格,零脚本。单位行为可低保真。
