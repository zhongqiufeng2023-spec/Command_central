# 情报失真管线 (Intel Distortion Pipeline)

> 蓝图 §十一、§十二。这是游戏的灵魂(支柱①)。原型战术核心。

## 统一管线 (四类失真都从这一条出)
每份战报 (`Dispatch`) **生成时**掷出三个属性:**延迟 / 完整度 / 可信度**。掷骰因子(相乘叠加):

```
失真程度 = f( 距离
            × 天气·昼夜          (雾 / 夜大幅恶化)
            × 观察者侦察技能
            × 观察者士气          (惊慌 → 夸大 / 失真)
            × 敌方善诈            (敌方主动放假情报)
            × 你的 SAN           (SAN↓ → 自己脑补 → 更假)
            × 难度 )
```
- 实现:走注入的 `IRandomSource`(可种子化,见 csharp skill §4)。
- "你的 SAN"这一项是 SAN↔迷雾双向绑定的落点 —— 原型可早期试水的完整层钩子。

## 四类失真
| 类型 | 表现 | 关键设计 |
|---|---|---|
| **延迟 (Delay)** | 所有情报的基础属性。呈现为「信息年龄:X 前」;超时未更新 → 褪色为半透明**幽灵标记 `GhostMarker`** | 基础层,人人都有 |
| **丢失 (Loss)** | 传令兵被拦截 / 阵亡 → 情报**永不达,且不给任何提示**(你甚至不知道本该有消息)。**最纯粹的迷雾** | 默认"纯沉默"。减负候选:低难度可对"主动派出的传令兵未归"给提示 |
| **残缺 (Incomplete)** | 标记带「?」字段(兵力不明 / 兵种不明 / 方向模糊) | 部分信息 |
| **失真 (Distortion)** | 看似言之凿凿却是错的(小兵惊慌夸大 / 敌方善诈放假 / SAN 低自己脑补) | **可信度提示 = 难度调**:低难度给显式「可靠 / 存疑」标;高难度拿掉,只能多源交叉比对 |

## 操作本体:矛盾情报并存
不同时刻的两份战报可**同屏并存**,玩家自己判断哪份可信 —— 这就是"拼图式认知"的核心操作。别替玩家消解矛盾。

## 安全垫:复盘
纯沉默 + 无提示很硬核。靠**战后复盘**揭示真相全貌,兑现"原来如此"的顿悟,把挫败转成学习(详见蓝图 §十四)。

## 难度旋钮控制的情报参数 (支柱④)
你方:情报延迟 · 丢失率 · 残缺率 · 失真率 · 可信度提示有无 · 传令兵 / 斥候数量 · SAN 衰减速率 · 丢失"未归"提示有无 · 免费基线信息量。
→ 低难度 ≈ "信息充足"模式,兼做新手教学。**信息为主 + 少量数值**,别用堆敌人数值替代信息难度。

## 等待期决策 (支柱③,接情报管线)
原型动作集:投入 / 回撤**预备队**(也有行军延迟) · 派传令兵**索要近况**(往返延迟,可能纯沉默) · 调**斥候侦察方向** · 排队**条件命令**(若…则…) · **简化佯动**(给敌方认知世界放假情报,复用本管线反方向)。
> 暂停语义:暂停可读情报 / 可排队意图,**不可即时下令**;意图恢复后才随传令兵出发(防作弊)。
