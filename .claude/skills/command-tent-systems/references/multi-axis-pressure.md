# 多轴压力 / 多结局失败系统 (Multi-Axis Pressure)

> 蓝图 §四。⚠️ **整体属完整层(里程碑三 / 四),原型不实现**(唯一例外:SAN↓→信息失真,见 intel-pipeline)。在原型阶段被问到时,温和提醒这是完整层。

## 结构:5 主轴 + 派生评估值
- **5 主轴**(0–100,是"因",各自独立触发各自结局):
  `Morale 士气` / `Provisions 粮草` / `Funds 经费` / `ImperialFavor 皇恩` / `Sanity SAN`。
- **伤亡 `Casualties`** = 累积计数器,不是条,是不断喂给其他轴的"毒"。
- **综合评估值 `SituationAssessment`** = 派生仪表盘(危殆 / 艰难 / 稳健 / 优势)。**只是预警表**:总览显示 + 影响皇帝态度 + 复盘评分。**不决定结局**。
- **结局 = 哪条主轴先被击穿**决定(各轴独立结局)。

## 压力网 ("越拖越难"自然涌现,无需脚本硬强化敌人)
- 伤亡 → SAN↓、士气↓、经费↓(抚恤)
- 粮道被断 → 粮草↓ → 士气↓
- 久拖不胜 → 皇恩↓ → 催战诏书 → SAN↓
- 经费↓ → 发不出犒赏 / 招不到兵 → 士气↓
- **SAN↓ → 认知世界可信度↓ → 误判 → 更多伤亡(死亡螺旋)**
- 掠夺 → 钱粮↑ 但民心↓ → 敌方抵抗↑ + 皇恩↓

> "敌人动态升级"的压力从这张网长出,不靠脚本硬编。

## 各轴:击穿 → 危机 → 挽回 / 结局 (两段式,留挽回余地)
| 轴 | 击穿危机 | 挽回 / 结局 |
|---|---|---|
| 士气 | **哗变**(内部战术战) | 哗变情报是迷雾的 → 甄别叛部 → 集结忠诚部队平叛;胜则士气部分恢复,败则瓦解终局 |
| 粮草 / 经费 | 抉择 | **掠夺**(民心↓ / 皇恩↓ / 抵抗↑)or **班师**(目标受挫 / 皇恩↓) |
| 皇恩 | **召你回朝** | **造反**(替代战役线,完整层 stretch)or 回朝迎降罪结局 |
| SAN | **疯了 / 自杀**(终局) | 见下方 SAN 回血 |

## 经费 vs 粮草 (两条分开)
- **粮草 `Provisions`**:持续后勤,逐日消耗,粮道被断则加速见底 → 崩士气。
- **经费 `Funds`**:可支配国库,招兵 / 犒赏 / 升级;掠夺 / 班师抉择主要挂钱粮危机。

## SAN 设计 (与迷雾母题双向绑定)
- **低落表现 = 绑迷雾**:SAN↓ → 认知世界更不可信(假标记、夸大战报、命令延迟变长、副将更易误解)。心态崩了,你眼里的战场就更假。
- **回血来源**(难涨易跌,每种花时间 / 资源):① 胜利 / 捷报 ② 安全驻扎 / 休整(耗天数)③ 家书 / 幕僚 / 祭祀(耗一个行动)④ 稳定清晰的情报(连续一致 → 回稳;长期信息黑暗持续掉 SAN)。候选未定:皇恩犒赏第 5 来源。

## 为何这套系统成立
1. 哗变信息也要侦察 → 迷雾延伸到军帐内部,连"自己人要反"都是滞后 / 残缺情报。
2. SAN → 把主帅本人变成要管理的资源,契合"孤独主帅困于中军帐"母题。
3. 哗变 = 内部战斗 → 复用同一套战术引擎 + 迷雾,架构上近乎零额外成本。
