# 中军帐 (The Command Tent)

> 一将功成万骨枯。

单人 PvE 战役模拟。你不是运筹帷幄的主帅，而是**奉命带一路偏师的副将**——坐在自己的中军帐里，隔着**延迟、丢失、失真的军报**去指挥一片你**看不见**的战场。

**卖点不是打仗，是看不见却要决断。**

---

## 核心机制：信息不对称

真实战场（`TruthWorld`）在后台持续推进，你**永远看不到它**。你看到的只是斥候、传令兵、瞭望台带回来的**滞后而失真的影子**（`BeliefWorld`）。

斥候回报是**判断**、不是事实：近处的敌军数得清，远处的只能报个约数、甚至认不清兵种。命令也双向失真——你的意图经传令兵送达，还要经副将按性格**二次解读**才落地。

**在雾里下注，是这个游戏的全部。**

## 你是谁

- **全程副将**：直辖 ≤8 队、每队 ≤250 人、每队配一名武将（骑砍式编成）。
- **中军是 NPC**：它发任务、可请援，并**隔着它自己的迷雾 + 政治**来评判你——**赢未必受赏，输未必受罚**。上报，是你操纵它认知的杠杆。
- **胜负是双层的**：战略结局（硬性）+ 任务评级（喂给政治）。不一定要打到全歼。

## 世界观

架空王朝**「大酆」**，以唐为骨（陌刀、明光铠、牙旗大帐）。国号「酆」双关**酆都冥府**，暗合主题。

敌人是多阵营的：草原虏骑、藩镇叛将……以及后续的**冥府邪祟**（战壕十字军式 grimdark × 中式冥府，打起来 SAN 值告急）。MVP / 第一关仍是人对人，超自然留给完整层。

## 兵种（非对称克制）

大酆六兵种（陌刀 / 枪槊 / 刀盾 / 弓弩 / 轻骑 / 具装重骑）对草原三兵种（骑射 / 突骑 / 部落步众）。
**弓射箭、骑冲锋、步抗线**各有其长，克制在混编层展开。

## 三层架构

生涯（升迁 / 猜忌） → 战略（骑砍式实时大地图） → 战术（一场看不清的战役）。
**范围纪律**：MVP 只做一场揪心的战术战，跑通、好玩了再往外扩。

## 技术架构

- **引擎无关内核** [`prototype/src/CommandPost.Core`](prototype/src/CommandPost.Core)：纯 C# / .NET 8，**零引擎依赖**。双世界模型 + 传令 / 斥候 / 旗鼓 / 瞭望台 + 战斗结算 + 敌方 Utility AI + 副将解读。确定性、可种子化，便于单测与复盘。xUnit 覆盖。
- **前端** [`godot/`](godot)：Godot 4.7 Mono (C#)，经 `ProjectReference` **零重写**复用内核。全程 2D（铁锈战争式像素兵海，无第一人称）。
- **理念**：深模拟在底、轻触感在上；**可玩性 / 娱乐性 > 史实严谨**（史实是佐料）；敌方 AI 是玩法支柱。

## 仓库结构

```
prototype/                引擎无关内核 + 单测 + 控制台原型
  src/CommandPost.Core/   双世界模拟内核（.NET 8，纯逻辑）
  src/CommandPost.Console/ 无头验证用控制台
  tests/                  xUnit 测试
godot/                    Godot 4.7 Mono 前端（复用内核）
  scripts/GameRoot.cs     战中直控视图
doc/                      设计蓝图 / PRD / MVP 实现计划 / 第一关脚本
.claude/skills/           项目知识速查（术语表 / 系统规格 / 编码约定）
Launch-CommandTent.cmd    启动器（把便携 .NET 8 SDK 顶到 PATH 前再开 Godot）
```

## 构建与运行

需要 **.NET 8 SDK**。

```sh
# 跑内核单测
dotnet test prototype/CommandPost.sln

# 编译 Godot 前端
dotnet build godot/CommandTent.csproj
```

前端用 Godot 4.7 **Mono/.NET** 版打开 `godot/` 工程后 F5 运行。
（Windows 上若系统 dotnet 无 SDK，用 `Launch-CommandTent.cmd` 启动编辑器。）
