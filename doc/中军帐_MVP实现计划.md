## 1. MVP 唯一目标
**验证:一场看不清的『副将奉命』遭遇战(侦察 / 支援 / 达成中军任务)是否「揪心、上头」。**
- 主题北极星:**一将功成万骨枯**(PRD §2)。基调:荒诞表层 + SAN 诡异暗流;**可玩性 / 娱乐性 > 史实严谨**(史实是佐料)。

## 2. MVP 范围
- **做(全程 2D)**:战前布阵(基础)· 实时(暂停/0.5/1/2/4x)· **副将带一路(≤8 队×≤250人×每队配武将×六兵种混编)** · **中军任务制胜负(双层)+ 主帅信任(轻政治)** · 传令兵(延迟/丢失/**去程失真**/多轮)· 斥候 · 旗鼓(进/冲/停/退/守/集结 + 方向)· 瞭望台工位(**2D 战场俯瞰**,自己估距手标)· 副将解读 + **主动回报 + 请示求决** · **战斗 A 档**(整体血量 + 混编修正 + 阵型/侧翼 + 崩溃连锁)· 简版复盘 · 一个难度档 · **占位 / 2D 像素美术**。
- **不做(完整层)**:战略大地图(**骑砍式实时 · 非回合;主帅任务非线性 + 敌 AI 要用心**)· 生涯/章节 · 多轴失败(SAN→失真可早试水)· 将领养成 · **3D / 第一人称**(本作走 2D 像素,万人兵海也用 2D)· 外交(劝降/骂阵)· 子部队位置 AI(战斗 B 档)。
