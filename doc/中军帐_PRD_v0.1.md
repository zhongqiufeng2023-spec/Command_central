## 1. 一句话定位
单机 PVE、冷兵器、古代战争**指挥官模拟**。你坐镇中军帐,**永远没有上帝视角**,只靠**滞后 / 残缺 / 失真**的情报,在一个**固定空间**里**实时**处理信息、下达命令。**卖点不是打仗,而是「看不见却要决断」。**
体验参照:Radio Commander、The Roottrees Are Dead(固定空间 · 实时信息处理)+《全面战争》式战后复盘。

## 2. 目标体验(核心情感)
- **揪心**:情报不全、还在变,却必须现在决断。
- **沉浸**:实景中军帐,靠帐内道具(沙盘 / 令旗 / 瞭望台 / 文书)指挥。
- **顿悟**:战后复盘对照真相,「原来如此」。
- **成长**:一位主帅的一生——老兵、将领班子、声望跨章节延续。
- **基调(已定)**:**表层轻松、人味、黑色幽默**(Radio Commander 取向)**+ SAN 带来的诡异压抑暗流**——笑着指挥这摊混乱,同时悄悄失去对自身感知的把握;二者互相放大(越荒诞越渗人)。方针:**深模拟在底、轻触感在上**——玩家只做少数高杠杆决断 + 享受有性格的混乱;AI「**蠢得合理**」是特色非缺陷(真实副将本就各行其是、会看错旗)。**可玩性 / 娱乐性 > 史实严谨**:历史是佐料和灵感,不是模拟枷锁;凡卡玩法的真实,一律让路。
- **主题 / 情感北极星(已定)**:**「一将功成万骨枯」**——孤身在帐中、隔着雾决人生死,功业是用自己人的万骨堆出来的。表层荒诞、暗流诡异,**最终落点是悲怆**;**轻是为了衬重**(越荒唐越沉痛,《第二十二条军规》式)。**检验**:每个系统最终是否服务于这份「功成 ↔ 万骨枯」的重量。
- **设定(已定)**:架空王朝**「大酆」· 唐基**(唐式兵种 / 制度 / 美术皮;**娱乐 > 史实**)。主帅 = 受朝廷之命的**边镇主帅(节度使式)**;久镇拥兵 + 皇恩猜忌 → **「造反线」从安史式母体天然长出**(国号「酆」双关酆都冥府,暗合万骨枯)。敌 = **多阵营**:人间(草原虏 / 藩镇 / 敌方副将)+ **超自然(冥府邪祟 / 邪教 / 妖魔;《战壕十字军》式 grimdark × 中式冥府,应国号「酆=酆都」;打之 SAN 重、诡异转明、怪物 AI 另一套)**〔MVP 仍人对人,超自然=完整层〕;章节题材 = 远征开疆 / 抵御草原 / 平藩镇 / 征逆贼 / **讨伐邪祟**。兵种(初定):陌刀 / 枪槊 / 刀盾 / 弓弩 / 轻骑 / 具装重骑。

## 3. 设计支柱(自洽性检验标准 · 参见蓝图 §八)
1. **迷雾即灵魂**:延迟 / 残缺 / 失真情报是灵魂本体,无一处给上帝视角。
2. **中军帐 UI / 道具**:点击帐内实物行使指挥,强实景。
3. **等待是玩法**:时间一直走,每个空窗 = 「再等一份情报 vs 现在就赌」。
4. **难度 = 信息丰度**:难度主要调信息(延迟/丢失/残缺/失真/提示),少量数值。

> 检验任何新机制:它强化哪条支柱?有没有破坏支柱①(给上帝视角)?

## 4. 双世界模型(技术与体验主轴 · 参见蓝图 §3.1)
- **真相世界 (TruthWorld)**:权威实际战场状态 —— **一场完整的战场模拟**(移动 / 接敌 / 损耗 / 士气 / 溃逃都真实演算)。**游戏的一切都建立在这场真模拟之上**,迷雾与延迟只是叠在其上的一层;复盘 = 把这场真模拟原样放给你看。玩家战中永不可见。
- **认知世界 (BeliefWorld)**:玩家靠情报拼出的图景(最后已知 + 信息年龄 + 幽灵)。玩家只操作这一层。
- **传令系统 (CourierSystem)**:两者间的延迟 / 失真中介。
- 这条主轴在三层架构里各复用一次。

## 5. 三层架构总览(参见蓝图 §三)
| 层 | 内容 | 时间尺度 | 阶段 |
|---|---|---|---|
| **战术层** | 单场战斗:固定空间实时信息处理(本作核心) | 实时(可暂停/调速) | **原型焦点** |
| **战略层** | 大地图战役:实时行军 / 经营 / 探查 / 对称迷雾 | **实时(同战术层,可暂停/调速)** | 完整层 |
| **生涯层** | 一位主帅的一生,跨章节延续元状态(声望/老兵/将领班子) | 章节 | 完整层 |
- 战术内核做成**纯函数**「战场状态 → 战斗结果」,战略层调用;两层解耦、可独立单测(参见蓝图 §3.5)。

## 6. 战术层(核心 · 详述)——中军帐实时信息处理

### 6.0 战前布阵(开战前 · 必要)
- **这是你信息最全、控制最强的唯一时刻**:开战前在沙盘上摆好**各部队位置 / 初始阵型 / 朝向 / 状态**,指定**预备队**;(完整层)再做**兵种配置 / 副将指派 / 阵型库 / 临阵换将(利弊)**。一旦开战,迷雾与延迟接管——你亲手摆的阵,只能隔着雾看它如何展开。「**满控 → 失控**」的落差本身就是体验。
- **史实依据**:前现代仗「一半在摆阵时就定了」(部署 + 士气 > 开打后的实时指挥;ACOUP《Total Generalship》)。故布阵是**核心,非边角**。
- **范围**:**MVP 做基础版**(摆位置 + 初始阵型/朝向 + 选预备队);**完整层**做丰富版。

### 6.1 时间模型(参见蓝图 §十八)
**时间持续流逝**,玩家可**暂停 / 减速 / 加速**(挡位:暂停 / 0.5x / 1x / 2x / 4x);**每支部队各自速度**(按兵种 / 体力 / 地形等权重)。
- **节奏(已定)**:一仗 **~20–30 分钟 @ 1x,从容**——留足读情报/思考的时间,时钟给压力而不手忙脚乱;可暂停思考,可 4x 跳过沉闷段。
- **写实锚点(已定)**:地图 **1 格 ≈ 50–100 米**,部队按 **km/h** 行进(急行军 ~10km/h 等),使「斥候报敌 10km/h 由东向西 → 几分钟后进瞭望台视野」的**接敌时间心算成立**(核心玩法)。**1x = 现实时间 1:1(无隐藏压缩),时间压缩全靠玩家调速(0.5/1/2/4x)**;具体格距 = 原型期边做边调的数值。
- **暂停语义**(防作弊):暂停可读情报、可排队意图,**不可即时下令**;意图恢复后才随传令兵出发(参见蓝图 §十二)。
- **收到情报自动暂停(已定)**:关键信息一到(新中军令 / 请示求决 / 斥候回报 / 接敌 / 某队告急)**自动暂停**给缓冲——尤防 4x 快进错过要情;哪些事件触发、可否关 = 难度 / 设置项。

### 6.2 控制单位与下意图(参见蓝图 §九)
- **控制单位 = 队(非士兵)**〔v2:玩家=**副将带一路**,覆盖旧「主帅」〕,各由一名**武将**统领;**直辖 ≤8 队**(每队 ≤250 人、六兵种混编,满编 ~2000)。**中军 = NPC**(发任务 / 可请援)。真相属性:位置 / 兵力 / 兵种 / 士气 / 体力 / 当前意图。沙盘只显「最后已知 + 信息年龄」。
- **部队编成 = 多兵种混编**:每支部队内含若干**子部队**(枪 / 弓 / 骑射 / 骑兵…),按**副将专长**配兵种。**子部队由副将自主指挥,玩家不直接碰**;唯有**副将战死 / 抗命**,玩家才可临场**派新将**或**老帅在大帐接管**这些子部队(危机载荷骤增)。**副将之死本身也是一条要侦察的情报**(你可能没及时知道,那摊子已乱一阵)。
- **精锐直控(骑兵 / 骑射 · B 档)**:这两类是部队精锐、占比少、最吃时机——玩家可**亲自直控**或**托管副将 AI**(玩家选)。**仍守迷雾**:精锐在你身边(瞭望 / 旗鼓可及)时可近实时微操;一旦**投出去做深远迂回 → 没入迷雾、按最后意图执行,你只能等延迟回报**——「把精锐撒进雾里」正是揪心戏。
- **预设条件命令**:可战前给整支部队编好「若…则…」条件令 + 初始阵型,直接投入(接 §6.6 / 蓝图 §十二)。
- **下意图 = 动词(移动/攻击/据守/后撤) + 基调(谨慎/常规/激进/不惜代价/见机行事) + 目标**;可含**阵型(默认副将定)/ 行进速度**。
- **副将解读 = 第二层迷雾**:同一意图,不同性格的副将执行有偏差(原型做轻量,养成见 §8.5 / 蓝图 §十)。**分层精修(史实)**:**旗鼓 = 绝对照令**(照令执行、不容自由发挥——戚继光「耳只听金鼓,眼只看旗帜」);副将的解读偏差主要发生在**传令兵带去的「意图」**上,不在旗鼓上。

### 6.3 空间与道具(中军帐 = 单一空间多工位 · 参见蓝图 §十六、§十八)
| 工位 / 道具 | 对应动作 |
|---|---|
| **沙盘 / 地图桌** | 认知世界主视图(标记 + 信息年龄 + 幽灵 + 玩家自标注) |
| **令旗竹筒 / 兵符** | 取令旗下意图、指派传令兵、掷斥候令旗 |
| **瞭望台** | 登台远眺(实时低保真);敌入视野小兵来报;台上可掷旗下令 |
| **情报案(文书堆)** | 逐份读战报、(低难度)标可信度 |
| **预备队令牌** | 投入 / 回撤预备队(战前选定) |
| **天象 / 沙漏** | 免费基线:天气、时间 |
| **军情记录册** | 战间经营 / 生涯层入口(完整层) |

**中军帐交互(已定:2D,非第一人称)**:玩家在 **2D 中军帐**操纵将军 / 点工位——**点瞭望台** = 切到 2D 战场俯瞰;**点沙盘** = 操作沙盘;**点令旗** = 发出对应指令。
**瞭望台 = 视角,不是自动情报(已定)**:登台看到的是**真实战场**(2D 顶视;**纯顶视即可**,2.5D 斜俯视为后置可选、纯为电影味)。
**2D 如何表现「距离」(已定 · 核心)**:顶视几何本是「免费且精确」的(玩家能数格子),故主动用**「清晰度随『离塔半径』衰减」**买回模糊——**近**:像素方阵清楚(阵型 / 朝向 / 大致兵力,`ScaleHint` 可靠);**中**:糊成一团 + 扬尘(一大股在动 + 大致方向,`ScaleHint±1`,位置误差变大);**远**:只见尘烟 / 反光(仅方向,或看不全)。清晰半径再 ×f(**天气 · 地形 · 高地**):晴 / 居高 → 半径大;雾 / 雪 / 沙 / 夜 → 半径缩;林地按通视做**扇形盲区**。**这一圈圈清晰度落差 = 2D 版的「距离关系」**(替代 3D 透视/雾霾白送的模糊)。
**看到 ≠ 入账**:实景是**转瞬即逝**的(下塔即无 —— 对应内核临时 `WatchtowerContact`,**不写 BeliefWorld**);你**主动手标**到沙盘的那个点才**写进 belief**(随后像普通情报一样**变旧 / 变幽灵**)。手标误差**按距离过渡(已定 · 丙)**:**近处听你的**(散布 ≈ 0,奖励爬上去看仔细),**远处归系统**(自动撒点),`scatter = f(距离 × 天气 × 难度)`。也可不标记就**直接发旗鼓**让部队行动。〔难度旋钮:低难度估算辅助 / 自动粗标且散布小;高难度无辅助、散布大。〕

### 6.4 信息渠道(战场感知系统 · 参见蓝图 §九「信息渠道总览」)
每条 = 真相→认知的一根「管道」,profile 互补,信息随距离自然衰减:

| 渠道 | 带宽 | 速度 | 触达 | 风险 / 泄密 | 状态 |
|---|---|---|---|---|---|
| **传令兵** | 高(详令 + 完整情报包) | 慢 | 几乎不限 | 拦截=纯沉默 | ✅ 内核 |
| **瞭望台(高处观察)** | 低(位置 + 规模档,无精确兵力) | 实时 | 以塔为圆心,**清晰度随半径衰减**(近清/中糊/远尘);雾夜林缩半径 | 双方互见 | ✅ 内核 |
| **旌旗 / 金鼓** | 低(进/守/退/集结) | 近即时 | 通视 / 在声程 | **敌可读 → 可佯动** | ✅ 内核 |
| **斥候** | 中(位置/兵种/规模/方向/速度) | 延迟(往返) | 可远;避敌绕道 | 可被歼 | ✅ 内核 |
| 多级层层汇报 / 审俘·间谍 / 烽火 / 军师汇总 | — | — | — | — | 完整层 |
> 《孙子·军争》:「言不相闻,故为金鼓;视不相见,故为旌旗。」

**传令兵回报内容(已定)**:部队近况(位置 / 士气)+ **接敌与战况**(接战 / 受创 / 占上风 / 将溃)+ 沿途所见敌情。
**再探再报(已定)**:传令兵回报完可**立即再派回去**,形成**常驻传讯线**——占住一名传令兵换「对该部队的持续(仍延迟)更新」;一次性派 vs 常驻循环由玩家定(《大明风华》朱棣式「再探再报」)。
**副将主动回报(已定 · 事件驱动)**:不只你「拉」,副将也主动「推」——前线一**发现敌军 / 接敌 / 受创 / 溃败 / 抵达**即派传令兵回报(不只低频定期);还可发**「请示求决」**(如「已接敌,请示是否进攻」)等你回令。仍守迷雾:这些回报照样延迟、可被拦截——你可能晚收到 / 收不到,甚至**不知道他正在等你拍板**。你不回 / 回得晚 → 副将按**基调·性格**自处(见机行事=自作主张 · 固守=死等 · 激进=不等就上)。属 MVP/A 范围。

### 6.5 情报失真四类(统一管线 · 参见蓝图 §十一)
每份战报生成时掷出「延迟 / 完整度 / 可信度」,因子 = 距离 × 天气昼夜 × 观察者侦察技能 × 观察者士气 × 敌方善诈 × **你的 SAN** × 难度。四类:
- **延迟**:所有情报基础属性;「信息年龄:X 前」,超时褪色为**幽灵**。
- **丢失 = 纯沉默**:被拦截 → 永不达且**无任何提示**(最纯粹的迷雾;低难度可对「主动派出未归」给提示)。
- **残缺**:字段带「?」(兵力/兵种/方向不明)。
- **失真**:言之凿凿却错(惊慌夸大 / 敌善诈放假 / SAN 低脑补)。**可信度提示 = 难度调**(高难拿掉 → 只能多源交叉)。
- **命令也会失真 / 丢失(去程,不只情报回程)**:失真双向——传令兵慌乱可能**记错命令**(送达成错动词 / 错目标 / 错基调),或半路、甚至**「到门口才死」**(末段亦可被拦,最痛的近失)→ 命令永不达。副将再按性格解读 → 可能**双重走样**;复盘才揭示(「你那道『进攻』在路上变成了『据守』」)。
- **矛盾情报并存** = 拼图式认知的操作本体;**复盘是安全垫**(揭真相、化挫败)。

### 6.6 等待期决策动作集(支柱③ · 参见蓝图 §十二)
- 投入 / 回撤**预备队**(招牌决策,也有行军延迟 → 赌时机)
- 派传令兵**索要近况**(往返延迟,可能纯沉默)
- 补派 / 调整**斥候侦察方向**
- **排队条件命令**(若…则…)+ 给在途传令兵**派护卫**
- **多轮 / 冗余传令兵**:重要命令一次派多名(各自独立掷拦截)→ 提高送达率;代价 = 占用传令兵资源(别处更慢=系统性延误),且每份可能各自记错、先到的为准(多派 ≠ 保证正确)
- **佯动 / 设疑兵**:污染敌方认知世界(复用失真管线,方向反过来)
- 〔完整层〕审讯俘虏 / 招降 · 巡营安抚 / 军议(提士气压 SAN)· 派死士 / 间谍策反
- **原型范围**:前 4 项 + 简化佯动。

### 6.7 战斗模型(参见蓝图 §九 / `command-tent-systems`)
- **算用整体血量,看用一堆小兵**:模拟层一支部队 = 一个**整体血量(= 兵力)**,部队级公式定胜负,**不逐兵模拟**;渲染层(复盘 / 景观)把整体血量**画成兵海**(兵力掉 → 小兵一个个倒)。理由:战时隔雾看不见单兵,逐兵模拟产生的信息用不上、成本却极高。
- **战力(逐 tick)** = 兵力 × **兵种构成克制对手构成** × 阵型 / 朝向适配 × 士气 × 体力 × 地形 × **侧翼 / 背击加成** × 副将统率 × 随机抖动。
- **结算**:互耗(战力高方令对方多掉兵力 + 士气);士气见底 → **溃逃且传染邻部(崩溃连锁)**;多面夹击 → 侧翼 / 背击惩罚叠加、集火速崩;相邻友军可支援 / 补士气,迂回敌侧翼 / 背后给大加成。
- **多兵种混编**:对战 = 你的混编 vs 他的混编的叠加 → **想赢先侦察敌军兵种构成**(信息更值钱)。兵种角色:弓 = 远程削弱 · 骑射 = 放风筝游走 · 骑兵 = 切角 / 对冲 / 收拾散兵援军 · 步兵 = 抗线主力。
- **深度分期(已定 ①)**:**MVP = A**(部队级公式 + 兵种构成当修正 + 行为靠渲染演);**完整层 = B**(子部队位置 AI + 精密兵种战斗 AI:弓骑真放风筝、骑兵真绕侧翼冲)。接管机制(§6.2)A / B 皆成立。
- **B 档兵种战斗 AI 规格(权重 / 规则即可,参《桌上谈兵》但把权重调对)**:
  - **步兵**:抗线主力,平时向前推进;见己方弓箭手被贴近 → 去支援。
  - **弓箭手**:射程内**优先射敌方弓箭手**;被贴近 → 后撤。
  - **骑射手**:优先射射程内敌军,但**先向部队左侧突进再射**;被追 / 被攻 → 往**己方阵列空位**放风筝回撤。
  - **骑兵**:多依指令;托管 AI 时 → **绕到敌背、优先冲锋其后方**。

### 6.8 黄金路径(用户故事)
1. **进场**:面前沙盘,左=令旗竹筒,右=沙盘道具 + 写着最新情报的白纸。时间开始走(可暂停/调速)。
2. **派斥候**:点竹筒取斥候令旗 → 掷向沙盘某点 → 斥候朝该向前进。
3. **斥候回报**:如「敌 500 步兵,坐标 X,由东向西急行军(~10km/h)」。据方向+速度估行踪与接敌时间。
4. **入瞭望台视野**:晴天平原双方互见,但需估距、判断其在沙盘的确切位置;**小兵来报**。
5. **登台**:看敌实际方位、估距,可在台上掷令旗(如招回防),再回营帐。
6. **近处传讯**:友军可视/声程内用旌旗+战鼓即时(持续擂鼓=持续前进,词表后补)。
7. **远处传讯**:用传令兵(延迟);回程带回该部队士气/位置/它发现的敌情。
8. **更新与再决策**:沙盘更新信息,估接敌时间;再派斥候/传令兵;或令副将见机行事/固守/推进/援友。

### 6.9 一局起止 与 战后
- **胜负分级**:大胜 / 势均力敌 / 险胜 / 惨胜 —— 不同效果。
- **胜后**:追击 / 派部分队伍追击 / 包围残军 / 打扫战场 / 整理军备 / 士气奖励。
- **败后**:留队断后 / 投降 / 带队突围 —— 依**敌方 AI**。
- **复盘**(§10)→ 回大地图。

## 7. 战略层(大地图 · 完整层 · 骑砍式实时 · 参见蓝图 §三)
- **v2 角色**:玩家=**副将**,战略层由**中军(NPC)主导**——你受命出征、被派往各战役;原「你=节度使自己跑战役」下沉为**完整层生涯**(升任主帅后)或改由中军担纲。
- **形态(v1 改:回合制作废)**:节点-连线为骨,队伍在边上**实时行军**;**连续时间,可暂停 / 0.5 / 1 / 2 / 4x**(无「结束本日」);完整对称迷雾(敌我进侦察圈才显形、出圈变幽灵;斥候扩圈刷新但回报延迟+失真)。
- **节点**:大本营(援军/粮草源)· 城(目标)· 关隘(咽喉)· 渡口(脆弱,夜袭高发)· 村镇(掠夺/征粮);边 = 地形 / 是否粮道 / 隘险。
- **行军(史为佐料、玩法优先)**:速度 = f(构成 × 辎重 × 地形 × 天气 × 体力士气 × 行军模式);常行军 ≈ 30 里/日;**急行军更快但掉队 + 疲劳 + 到达只有一部分能战**(孙子「十一而至/半至」机制化);大军更慢、纵队有长度、过隘口渡口慢且脆;弃辎重换速度 = 豪赌。
- **主帅任务 = 非线性真决策**(随时做,不照流程走):① **查粮草账目**(粮官可能克扣/做假,自家补给数也是迷雾)② **选拔将领**(候选有性格/故事/毛病,可能吹牛——是赌)③ **接斥候军报**(延迟、矛盾、措辞有人味:慌张/夸大/错字)④ **决定扎营 vs 夜行**(择营高地近水可守 vs 趁夜赶路:快但疲、易遭夜袭、士气/SAN↓)⑤ **改路线 / 定行军序列**(绕威胁、调前锋/中军/后卫/辎重、护粮道、撒游骑屏蔽)。
- **娱乐性优先**:系统尽量有人味、有黑色幽默(贪墨粮官、慌张小兵军报、爱吹牛的候选将);**史实是佐料不是枷锁**,卡玩法的真实让路。
- **章节 anthology**:共用一套战略引擎,只换地图/目标/敌将/主打战斗形态——远征开疆 · 平定叛乱 · 征讨逆贼 · 抵抗侵略(守城→反攻)。
- **经营**:部署补给线;征兵买马;**部队自由编制与命名**(前锋/左右翼/中军/守军/预备/后备,不限六支,可细分命名);规划配置与领导;**提拔军官/副将**。
- **遇敌**:追击 / 守城 / 攻城(各有利弊);**接触**:劝降 / 骂阵(按程度给 buff·debuff)。
- **敌人在实时地图上(决策有意义全靠它)**:敌将也实时行军/扎营/撒斥候;抢目标 · 截粮道 · 隘口渡口设伏 · 夜袭脆弱点 · 佯动放疑兵。**→ 敌方 AI 要用心,见 §9。**
- **战前准备(已升为核心,见 §6.0)**:沙盘预规划我军位置/初始阵型/状态;完整层加**兵种配置 / 临阵换将(利弊)**→ 开战进入战术层(§6)。

## 8. 生涯层 & 进度 / 规模(完整层)

### 8.1 身份与规模(v2 重构:全程副将·带一路,覆盖旧「全程主帅」)
- **玩家 = 一路副将**;**直辖 ≤8 队**(每队 ≤250 人、配一名**武将**、六兵种混编,满编 ~2000)。**中军 = NPC**:发任务、可请援、隔着雾+政治评判你。
- **规模**:你这一路满编 ~2000;整场战役可更大——**友邻各路 + 敌军 = NPC**,你只从斥候 / 瞭望瞥见。你手上始终 **≤8 个 token**。
- **命令顺层级走样(第二层迷雾)**:你下的令经**队级武将**按送达那刻实情 + 你的基调解读执行——正是「在雾中揣摩上意」这一层,现在你自己就站这个位置。
- **生涯(完整层)**:副将做得好 → 升迁(带更大命、更多队,乃至最终升任主帅)——早先想要的成长线归此。

### 8.2 跨章节延续 与 终局(参见蓝图 §3.2)
- 延续元状态:声望 / 老兵 / 将领班子 / 皇恩 / SAN。
- 终局:随时可读档;终局可读回继续或重开;章节间设「班师受赏/休整」喘息节点,SAN/皇恩**部分恢复**(防死亡螺旋);失败可分叉**造反**线(stretch)。

### 8.3 战后→战略循环(本轮新增)
战后复盘 → 回大地图 → **派人回皇都汇报战果 → 获更多粮草/金银**(接经费/粮草轴 + 皇恩)→ 继续征战。

### 8.4 多轴压力 / 多结局失败系统(参见蓝图 §四)
- **5 主轴(0–100)**:士气 / 粮草 / 经费 / 皇恩 / SAN;**伤亡 = 喂给其他轴的计数器**;**综合评估值** = 派生仪表盘(危殆/艰难/稳健/优势)。**结局由「哪条轴先被击穿」决定**。
- **压力网(越拖越难自然涌现)**:伤亡→SAN/士气/经费↓;粮道断→粮草→士气↓;久拖→皇恩↓→催战→SAN↓;经费↓→犒赏/招兵↓→士气↓;**SAN↓→认知更不可信→误判→更多伤亡(死亡螺旋)**。
- **击穿→危机→结局**:士气→哗变(内部战术战)· 粮草/经费→掠夺 or 班师 · 皇恩→召回(造反 or 降罪)· SAN→疯/自杀。
- **经费 vs 粮草分开**:粮草=持续后勤逐日耗;经费=可支配国库(招兵/犒赏/升级)。
- **SAN 绑迷雾**:SAN↓→认知更假;回血来源:胜利捷报 / 安全休整 / 家书军议 / 稳定一致的情报。**原型可早期试水:SAN↓→信息失真**(nice-to-have)。
- **基调重标定(已定:荒诞表层 + SAN 暗流)**:整体走**荒诞可笑的表层 + SAN 诡异压抑的暗流**(二者互相放大)。**SAN 保留为核心轴**——招牌表现 = **SAN↓→认知世界更不可信**(沙盘骗你、幻影战报、副将更难捉摸),与迷雾母题双向绑定,这正是「诡异」来源。**但 SAN 当暗流/调味,不做碾压式死亡螺旋**(那才叫沉重)。真正留**可选 / 完整层**的是大系统(**哗变内战、造反线**);极端结局(疯/自杀)保留,但按黑色幽默 + 诡异的调子演,不猎奇。

### 8.5 将领养成(指挥班子 · 参见蓝图 §十)
- **属性**:性格(驱动解读=第二层迷雾)/ 统率 / 兵种专长 / 背景+忠诚+年龄。
- **来源**:从小队长/百户提拔;战后表现突出者「涌现」,自带背景故事。
- **与迷雾咬合**:**熟悉度降低迷雾**(用熟的班子可预测);**将领之痛**(依赖的将阵亡/叛变 → 失去可预测性 → 迷雾骤增)。

### 8.6 政治赏罚(v2 新增 · 副将向上的评价系统)
- **核心**:主帅隔着**雾 + 政治**看你 → **赢不一定赏、输不一定罚**。评价 = **中军所知结果 × 遵命度 × 代价 × 关系 × 运气**(**不含真实功过**)。
- **回报 = 杠杆**:你报什么 / 传没传到 / 可不可信,直接塑造主帅认知(诚实 / 隐瞒 / 夸大,各有风险)——把迷雾延伸到你的仕途。
- **典型戏**:报捷未达=白干;抗命而胜=看主帅性格(重果则赏、重规则记「跋扈」);奉命而败=非战之罪可免责;惨胜折将=赏打折;抢功 / 背锅;谎报被戳穿=信任暴跌。
- **主帅性格**:重结果 / 重规矩 / 多疑 / 惜才…你先后跟不同主将。
- **分寸**:MVP-轻 = 一条「主帅信任」+ 少量政治事件 + 2–3 主帅原型(信任高→请援易 / 补充足 / 给好兵将;低→苛刻任务 / 少援 / 易背锅);完整层 = 多轴(皇恩 / 派系 / 宫廷)+ 生涯升迁。

## 9. 敌方 AI(参见蓝图 §十五)——**战略层是不是真决策,全看它**
- **地基 = 对称迷雾**:敌方有自己的认知世界/延迟,基于不完全信息决策。
- **架构(混合)**:战术层 **Utility AI**(按「敌方认知下收益」打分);完整层战略叠 **GOAP** 串多步计谋(诱敌→断粮→围歼)。
- **战略行为库(实时地图)**:敌将也实时行军/扎营/撒斥候;抢目标 · 截粮道 · 隘口渡口设伏 · 夜袭脆弱点 · 佯动放疑兵 · 势弱避战/势强寻战 · 骚扰纵队 · 坚壁清野。
- **性格 = 效用权重向量**(激进/谨慎/善诈/稳健/贪功/吝啬),改权重即改性格,零脚本。
- **「蠢得合理」是特色**:求可信 + 会反应 + 有性格,不求最优解;**娱乐性优先**——宁可敌将偶尔上头犯傻(贪功冒进/疑神疑鬼)成你可抓的破绽(参《桌上谈兵》「调好权重」)。没有会反应的对手,实时战略地图就是空跑。
- **敌将可知度**:开局简报给**可能不准的估计**(善诈者尤易被误标)——「敌将是谁」也是迷雾。
- **能力档 = 难度调**(看多清/想多准/延迟多短),不灌数值。

## 10. 复盘系统(战后回放 · 参见蓝图 §十四)
- **三目的**:兑现「原来如此」顿悟 · 学习闭环 · 给硬核迷雾兜底。
- **道德清算(主题载荷)**:复盘不只「原来如此」,还有**「原来…是我害的」**——你看到那些因迟到 / 走样的命令而死的人;**兵海 = 万骨**。这是复盘最重的情感载荷,落点在主题(§2 一将功成万骨枯)。
- **核心**:认知 vs 真相**对照回放** + **自动标关键分叉点**(「T+12 你以为敌在桥头,实际已渡河」)+ 关键决策回顾;**揭全图真相**(上帝视角只在战后)。
- **呈现**:**2D 像素兵海(铁锈战争式)**,不做 3D;**抽象沙盘 ↔ 像素战场**的反差是顿悟载体。
- **评分/统计**:平均情报时效、丢失情报数、基于错误情报的误判数;产出战功→干部涌现、捷报式 SAN 回血。
- **原型已落地**:控制台 `replay` 逐 tick 上帝视角动画(战中隐藏斥候/传令兵,复盘才显形)。
