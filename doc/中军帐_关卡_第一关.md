# 《中军帐》关卡设计 · 第一关《黑松岭》

> **关系**:本文件 = 具体关卡脚本(实例),遵循 `中军帐_PRD_v0.1.md` / `设计蓝图_v0.2.md` / `给Claude的接手须知.md` 的 **v2「全程副将」** 框架(接手须知 §2 覆盖项 5)。
> **性质**:设计记录 ≠ 开工指令。同时是**首个验证内核契约**(建军 / 任务 / 全雾开局 / 回报塑造上级认知 / 请援 / 政治评价)的可玩样本。
> **设定皮**:大酆 · 唐基架空。

---

## 0. 空间模型:副将坐在哪 —— 「本路中军帐」(所有关卡通用)

一个「路 / 军」本身有前中后、有自己的中军。所以:

- **你 = 一路副将,坐镇「本路中军帐」**——在你这一路阵线**之后**,有**真实坐标**。游戏名《中军帐》正落在你身上。
- **你之上还有主帅的「帅帐 / 大营」(NPC)**,在全军更靠后 → **两段延迟链**:① **帅帐 → 你**(中军令送到要时间、会晚);② **你 → 你的队**(你的令送出去也要时间)。情报回程同理两段。
- **你的帐 = 信息枢纽**:令骑在此往来(收帅帐令 / 发回报)、斥候从此撒出、你的队回报到此、**旗鼓从此帐发**(范围 = 通视 / 声程)、**瞭望台就在你帐**。
- **可前移中军帐**:随路推进可移帐 —— 离自己的队更近(令骑 / 旗鼓更快),但**离帅帐更远**(军令 / 回报更慢)、**更暴露**。
- **敌摸到你帐 = 危机**(指挥中枢被冲,大乱 / 可能直接败)。
- 「中军帐 UI(沙盘 / 令旗 / 瞭望 / 情报案)」原封不动,只是它现在是**你这个副将的帐**。

## 0.5 时间与节奏(通用)
- **1x = 现实时间 1:1**(无隐藏压缩);玩家用 **暂停 / 0.5 / 1 / 2 / 4x** 自行加速减速。暂停可读、可排队意图,**不可即时下令**(防作弊)。
- **收到情报自动暂停**:关键信息一到(**新中军令 / 请示求决 / 斥候回报 / 接敌 / 某队告急**),**自动暂停**给你缓冲读与决断——尤其防你 4x 快进时错过要情;恢复后排的意图才随令骑出发。〔哪些事件触发、可否关,留作难度 / 设置项。〕

## 1. 关卡定位
**教学关**:一关跑通全套核心循环(派斥候 → 读延迟情报 → 令骑往返 → 请援 → 回报塑造上级认知 → 抗命抉择)。难度放宽、主帅宽容。

## 2. 你的兵(编成示例)
前锋一路,**8 队 · ~2000 人**:枪槊 ×2、刀盾、陌刀、弓弩 ×2、轻骑、具装重骑。
带性格的武将(各自解读你的令 = 第二层迷雾),举两个调味:
- **秦锐**(轻骑 · 贪功):老想冲,给"进攻"倾向的令容易过头。
- **王朗**(陌刀 · 持重):稳,给"据守"能钉死,催他猛攻会打折。

## 3. 开局态势(全雾)
沙盘上**只有你自己 8 队的位置**;**前方、左翼全是雾**。帅帐在你身后(NPC:**征西大将军 · 周崇**,第一关设为**「重结果」型**)。

## 4. 中军令 · 分阶段送达(有时间先后)

### 第一道(开局,已在案头)
> 「前锋听令:进抵**黑松岭**一线,**试探当面之敌**,探明其**人数、兵种、阵型**,速回报本帅。未得将令,不得浪战。」
- **目标 A(主)**:侦明当面敌军(位置 + 规模 + 兵种 + 阵型,达到"较可信")。
- **目标 B**:把敌情**回报帅帐**(令骑送达才算)。
- 预期玩法:撒斥候探雾、控队缓进、别过早接敌。

### 第二道(约**开战 20 分钟 · 游戏时间**发出;**令骑再赶几分钟才到你帐 → 你更晚才收到**)
到约 20 分钟游戏时间,帅帐才发觉左翼吃紧、遣令骑来(那时你也许已陷在当面之敌里,进退两难):
> 「左翼吃紧,速往驰援!」
- ⚠ **帅帐给的左翼位置 = 它的旧认知(可能过时 / 偏)**——你要**自己派斥候 + 同时赶过去**确认真实位置与战况。
- **目标 C(主)**:驰援左翼,协助其击退当面之敌。
- **目标 D**:把左翼战况**回报帅帐**(不报也行,但影响主帅看法)。

## 5. 场上 NPC(敌我对称)
- **当面之敌 = 敌军一路副将**(对称:~8 队 / ~2000,自己也带武将、也撒探马、也在雾里判断你)——**势均力敌的对手**,别指望碾压。
- **左翼友军一路**(NPC · 副将李嵩;自己会打,你不救可能崩)。
- **左翼之敌 = 另一路敌军副将**(正压着李嵩打)。
- 〔阵营〕**本关 = 人间阵营**(对称副将,教学最干净);世界观另有**超自然阵营**(冥府邪祟 / 邪教 / 妖魔,应国号「酆=酆都」),留作后续章节 / SAN 震撼引入。

## 6. 胜负(双层 · 灵活多路径)
- **硬性胜**:左翼没崩(你及时驰援击退)。**硬性败**:左翼崩溃,或你部覆没。
- **路径**:
  1. 侦察 → 回报 → 驰援 → 破敌(标准,评级最高)。
  2. 没探清就跟当面敌干、赢了再腾手驰援 —— 也行。
  3. **抗命**:你判断帅帐的左翼情报是错的,坚持打当面之敌、把敌军中路打崩 —— 真赢了也算硬性胜(但主帅记你一笔"抗命")。
- **评级(喂政治)**:侦明 + 回报 + 及时救 + 损失小 + 遵命 → 高;报捷未达 / 惨胜折将 / 抗命 / 见死不救 → 各扣。

## 7. 政治收尾
战后主帅按**他所知的结果**评你 —— **你若没回报,他可能根本不知道你救了左翼 → 白干**。
第一关主帅 = **「重结果」型**(抗命而胜也认),新手不至于因抗命被劝退;后续关卡换**「重规矩 / 多疑」**型主帅,同样操作赏罚就变(接 PRD §8.6)。
