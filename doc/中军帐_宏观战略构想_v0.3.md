# 《中军帐》宏观战略构想 v0.3 —— 从「章节剧本」到「活的乱世」

> **性质**:设计记录 ≠ 开工指令(项目铁律)。本文件把 2026-07-09 的宏观构想固化下来,
> 作为**完整层的北极星 v2**,覆盖/扩展蓝图 v0.2 §三(三层架构)与 §四(多轴失败)的完整层部分。
> **战术层(双世界战斗)一字不动——它是永远的核心资产与灵魂。**
> 三份旧文档(蓝图/PRD/MVP计划)关于战术层与第一章的内容继续有效。

## 1. 一句话

融合 全面战争/钢铁雄心/群星 的宏观战略 与 骑马与砍杀 的角色培养和微观队务,
玩家是大酆的一名**活生生的将军**——一边替朝廷打仗,一边与各方势力政治周旋、
经营自己的钱粮兵源,在乱世里活下去、做大做强,乃至改写自己的身份。

## 1.5 序章(骑砍式 · 2026-07-10 修正版,已实现)

- **玩家出身 = 将军**(如骑砍的出身设定):开局即在大地图上,带一路人马,身属皇帝阵营。
- **序章 = 一场战斗作引子**:开局一道皇命(侦破黑松岭之虏,限三日,毋掠民毋纵虏)
  给出初始目标与约束;这一仗跑一遍完整循环(行军/扎营/布阵/战斗/复盘)——
  **教学 = 玩本身**,游戏不弹一句教程,操作说明躺在菜单里。
- **战斗结束(无论胜负)即自由**:限期随接战而了结,不再催令;
  **玩家仍属皇帝阵营**——行营照常谒见、领粮、补员;此后去哪、做什么,全由玩家探索。
- **没有剧本事件**:不搞「注定覆灭」之类的强制剧情;世界只提供地理与势力
  (虏帐、边镇、京畿方向、东南混沌瘴土〔踏入者心神日蚀〕),路是玩家自己走出来的。
- **无通关、无结算面板**:没有「章末」;造反/降虏/入混沌等身份转变属 L3/L4 的系统,
  不靠序章剧本给出。

## 2. 天下大势(四方棋局)

| 方位 | 势力 | 威胁形态 | 备注 |
|---|---|---|---|
| 西北 | 草原游牧诸部 | 袭扰、劫掠、大举入寇 | 现第一章之敌,已有兵种组 |
| 东北 | 独立藩镇 | 拥兵自重、伺机造反 | 人间阵营;可战可交 |
| 东北+东南 | 异端邪教(冥府线) | 渗透、暴起、突入 | **国号「酆」双关酆都——立项即埋的超自然阵营**;打之 SAN 重 |
| 中央 | 大酆朝廷(皇帝) | 猜忌、催战、掣肘 | 你的名义主上;皇恩是资源也是枷锁 |

- 各方势力**互相之间**也有战争、和谈、贸易——今日交战,明日互市;
  每一场战斗或边境摩擦都可能成为更大战争的导火索。
- **NPC 对 NPC 的战争**照常发生并改变地图态势(技术:调战术内核纯函数做快速结算,不渲染)。

## 3. 皇命系统(从「中军令」长出来)

- 皇帝直接下达任务(讨伐/驻防/护粮/筑城),附**少许硬约束**:
  限时、拨付的军饷粮草额度、行为约束(毋掠民/毋擅和/毋越境……)。
- 完成/违约都进政治账:皇恩、朝中风评、政敌的弹章。
- **现有系统即雏形**:中军令时间线、任务时效催令、行营裁断、主帅信任——升格为皇命即可。

## 4. 经济层(自己养活自己)

- **封地**:食邑/防区——税收、民心、开发度;竭泽而渔换短期钱粮,代价是民心与长期产出。
- **商队**:路线×货品×风险;战争即禁运,乱世行商=高险高利;商队也是**情报源**(顺路带回各方消息)。
- **征兵**:朝廷额度之外,可**假借名头征兵**(借「防秋」之名多募两千)或**强征**——
  兵是有了,民心、朝廷观感、兵员质量各付代价。
- 军饷发不出 → 士气崩、哗变(蓝图 §四压力网原样适用)。

## 5. 势力模拟(自由度的来源)

- 每股势力 = **目标 + 资源 + 性格权重向量**的 Utility AI(沿用敌将 AI 的成熟做法,放大到势力级)。
- **关系矩阵**:战争/敌视/中立/互市/盟好,随事件流动;玩家的每次选择(受命/抗命/私下和谈/贸易)都在改写自己与各方的关系。
- 「蠢得合理」原则不变:势力 AI 求**可信+会反应+有性格**,不求最优解。

## 6. 身份自由(最后放开的缰绳)

忠臣 → 权臣 → 军阀 → 叛将(安史式造反线,设定原生)→ 投虏 / 入教 / 讨伐冥府。
玩家不再只是接令的副将,而是可以选边、骑墙、自立的棋手。

## 7. 支柱自洽检验(老规矩)

- **支柱①迷雾即灵魂,不破**:战斗层双世界原样;战略层的迷雾换形态——
  你知道的天下大势也是**旧的**:邸报延迟、风闻失真、商队情报有立场;势力关系你只能推断。
- **主题「一将功成万骨枯」,不破**:盘子越大,万骨账越沉;做大做强的每一步都有人垫底。
- **可玩性>史实**、**深模拟在底轻触感在上**,照旧。

## 8. 分层路线(铁律:每层可玩、可收档、验证好玩再进下一层)

| 层 | 内容 | 状态 |
|---|---|---|
| **L0 战斗内核** | 双世界逐兵战役(令骑/迷雾/武将/政治裁断/复盘) | ✅ 已完成(feature/road-to-release) |
| **L1 开放边野 + 皇命流** | 一张开放大地图,**无章节剧本**(2026-07-10 用户已否决章节制,Beat 状态机已删):开局即自由,皇命(目标+限期+约束)源源而来,打完一道来一道;逐步铺西北御虏/东南讨邪教/东北平叛的**区域与敌人**(内容以地区与皇命呈现,不以「章」呈现)。**做完即是完整可发售的游戏** | ← 当前(首道皇命=黑松岭已可玩) |
| **L2 经营层** | 封地+商队+征兵补员+军饷,五轴全量化 | 规划 |
| **L3 势力模拟** | 关系矩阵+势力 Utility AI+NPC 间战争(内核纯函数 auto-resolve) | 规划 |
| **L4 身份自由** | 抗命/造反/改换阵营/冥府线 | 远期 |

- **头号风险仍是范围**:L3/L4 是骑砍+全战体量;分层的意义就是任何一层停下来,手里都有一个完整的游戏。
- **美术并行**:用户自制 TileMap/人物/UI(见记忆 godot-editor-diy-assets),各层复用。
- **美术与变现的既定决策(2026-07-11)**:**AI 生成只进工具链,不进运行时**——
  用 AI 图像生成批量产各势力装备/素材,再当普通资源打包(「工厂化产一整套」的好处全留,
  美术方向由作者把关)。**不做「玩家上传照片→运行时生成」**:人脸属敏感个人信息(PIPL 单独同意/
  必要性/删除规则)、生成式 AI 服务的备案与内容标识、必需的内容审核、Steam 商店页 AI 披露,
  且需要后端+支付+配额+滥用防护——把单机变成一项服务,对个人开发者是压垮性负担;
  加之本作在 50:1 兵形与沙盘标记下**装备几乎不可见**(唯一近看处=帐内将军立绘,仅一张图),
  付费点没有屏幕存在感。**玩家表达改用部件组合**(手绘 冠/袍/披风/法器/纹章 × 可调配色):
  离线、零风险、全在作者画风内。**钱放在买断价里,不放在游戏内。**

## 8.5 魔导层(2026-07-11 新增)

用户定向:**冷兵器时代的《幼女战记》**——主角是拥有超量魔力的将军,
一人可击溃一部却无法决定一场会战,**上限由取舍构成而非规则写死**。
术士队 = 第七兵种;主角亲征 = 用「全局的耳目」换「一处的眼睛」;
主帅坠地 = 实时争夺(威望决定救主还是溃散);死则**骑砍式子嗣继承**。
各方对魔法的态度构成国策(用而防之 / 萨满 / 募而用之 / 其道即术 / **禁术**)。
→ **完整规格见 `中军帐_魔导战争设定_v0.1.md`**;开工顺序:战术层先行(术士队+亲征),
政治与传承随 L2/L3 叠加。

## 8.6 政治层核心机制(2026-07-11 新增)——虚伪的政治面纱

用户定向:这将是一个**充满战争的世界**——理想与利益、道德与阴谋、战争与和平并存。
关键在于:**这份复杂度必须是长出来的,不是写出来的**。为此只需要一组很小的规则:

### 铁律:把「原因」和「理由」分开建模

- **原因 = 利益**(势力真实的效用函数):那块地、那条盐路、那个碍事的邻居。**玩家永远看不到。**
- **理由 = 道义**(对外宣称的口实):尔纵兵掠我边民、尔窝藏叛将、尔行禁术亵渎神明。
- **开战流程不是「出事→开战」,而是反过来**:
  **先有意图(利益驱动),再回头去事件流里翻一个说得过去的口实。**
  → 这一句就是「虚伪的政治面纱」的机制定义。

### 由此白送的四件事(都不需另行设计)

1. **支柱①在政治层的形态**:玩家只看得到檄文,看不到算盘。
   **战略层的迷雾不是「看不见军队」,而是「看不懂动机」**——双世界模型原样适用,不必另发明哲学。
2. **任何事都可能成为引子**:口实从事件流里捡。你三个月前纵容部下劫的那个村子,
   当时无人在意;等到有人想打你,它就被从档案里翻出来写进檄文。**过去会回来找你。**
3. **玩家也能造口实**:阴谋成为玩家手里的工具,而不只是背景板——想打谁,先给自己造个理由。
4. **言行背离度本身是可观察的信息**:言行一致的势力(可能真有理想)可预测、可信赖,
   **也因此可被利用**;说一套做一套的势力危险。玩家可从其历史言行差距推断下一次檄文有几分真。

### 国策 = 行为权重,不是设定文本

对魔法的态度 · 对贸易的态度 · 对盟约的信用 · 扩张欲 · 内部稳定 —— 全部喂势力 Utility AI。
**且国策会变**:一个禁术之国忽然开始养术士,这件事本身就是最响的战争预警。

### 唯一现在就该做的:编年史(事件流)

每一场战斗、每一次劫掠、每一次遭遇、每一次你路过却没管的事,都记一条:
**谁 · 对谁 · 在哪 · 何时 · 死了多少 · 谁看见了。**

- **现在就有用**:大地图「边野传闻」(你听说别人做了什么)+ 你自己的功过账;
- **以后是燃料**:口实从这里捡、名声从这里算、势力关系从这里推、檄文从这里写;
- **这是唯一一件「不现在做,以后就没有历史可查」的事**——政治系统本身属 L3,不在 L1 站稳前开工。
