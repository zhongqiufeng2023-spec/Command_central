# 《中军帐》无缝世界架构 v0.1 —— 去掉战略/战术的界线

> **性质**:架构方向文件(设计记录 ≠ 开工指令)。固化 2026-07-11 用户定向:
> **不要两种模式**——所有部队、所有势力活在同一张地图上,行军/扎营/接战连续发生。
> **本文件修订**蓝图 v0.2 §三「三层架构」中战略层与战术层的**分离**假设;
> 双世界模型(真相/认知/传令)与四大支柱**原样有效,且被强化**(见 §3)。

---

## 1. 一句话

**一张世界,一支军队,一条时间线。** 玩家带兵四处征战,行军、扎营、警戒、遭遇、接战、
打扫战场,全部发生在同一张连续地图上——**没有「进入战斗场景」这回事**。

## 2. 三级模拟 LOD(用户原话:远处不刷模型,但依然是活的)

| 层 | 范围 | 表示 | 已有资产 |
|---|---|---|---|
| **逐兵层** | 玩家视野内(实体化) | 每兵一实体,10Hz | `BattleSim` ✅ |
| **队伍层** | 视野外的整个世界 | 位置/兵力/状态/意图,按时辰推进 | `WorldParty` + `AutoBattle` ✅ |
| **地貌层** | 全图,任意精度 | 连续噪声,粗细一致 | `WorldGen` ✅ |

**缺的只有中间那座桥**:实体化 / 去实体化。
- 队伍进入玩家视野 → 展开成逐兵(按当前兵力、状态、朝向、疲惫生成);
- 离开视野 / 脱离接触 → 折回队伍抽象,**兵力与状态守恒**;
- 折叠时正在交战 → 交给 `AutoBattle` 接着打(它本来就是按时辰算的)。

**地形的粗细一致性**:`WorldGen` 是连续噪声函数,可在任意精度采样——
战略尺度粗采样出地貌,走近了细采样出 16m 精度的战术地形,**同一个种子,天然对得上**。
(实现细节:归一化常数需全图统一,不能在局部重新 min-max。)

**建议比例**:1 战略瓦片 = 16 战术瓦片 = 256m → 世界 200×130 战略瓦片 ≈ **51km × 33km**;
一个典型战场(96×50 战术瓦片 ≈ 1536×800m)约占 6×3 个战略瓦片。

## 3. 视野即迷雾(支柱①被强化,不是被破坏)

「玩家视野内可见所有单位」乍看像上帝视角,实则相反——**只要视野是真实的物理视线**:
受距离、地形遮挡、烟尘、天候、昼夜限制。

> 你的部队铺开数里,**绝大部分本来就在你视线之外**。
> 想知道那边如何,仍然只能靠斥候、令骑、军报。
> **迷雾从一条 UI 规则,变成了一个物理事实。**

沙盘不再是「玩家唯一视图」,而是「**你视线之外那部分世界的、二手的、过期的**拼图」——
这个定位比原来更硬,也更好解释。

## 4. 扎营完备度 = 指挥能力(本架构的核心创新)

**把「两种模式」换成一个连续量。** 现有四条指挥通道按扎营完备度逐级开启:

| 完备度 | 情形 | 可用通道 |
|---|---|---|
| 高 | 从容择地、立营设栅、瞭望台架起 | 完备沙盘 · 令骑有备马 · 旗鼓齐备 · 瞭望台 |
| 中 | 仓促列阵 | 简易沙盘(只标目视所及) · 令骑 · 旗鼓 |
| 低 | 遭遇突袭 | **无沙盘**——马背上口传,目视范围内喊话;令骑找不到人;旗鼓来不及擂 |

- **完备度由行为决定**:选址(地形)、扎营耗时、士卒疲惫、是否设岗警戒、是否有辎重;
- **指挥界面成为要靠准备去挣的资源**——这正是「等待是玩法」(支柱③)的最强形态。

## 5. 行军日常:每一项都必须配一个风险

> **铁律:真实 ≠ 好玩,风险才让真实变好玩。**
> 不做会出事的日常才是玩法;不会出事的日常是点击杂务。加任何一项前先写清它对应的风险。

| 日常 | 不做的后果(即它存在的理由) | 复用 |
|---|---|---|
| 斥候前出 | 撞进埋伏 / 不知敌之所在 | 塘骑物理 ✅ |
| 巡岗警戒 | 被突袭(扎营完备度归零开战) | 令骑物理 ✅ |
| 择地扎营 | 完备度低、被围、无水无柴 | 地形系统 ✅ |
| 打扫战场 | 丢失缴获与伤兵(伤兵不收=直接进万骨账) | 新增,小 |
| 收拢溃卒 | 兵力不归建 | 已有 Fled 机制 ✅ |

## 6. 时间流速与「加速泄露敌情」这个坑

无缝世界必须有时间加速(否则行军三日要坐三日)。**但**:

> ⚠ 若在敌军接近时**自动禁止加速**,等于直接告知玩家「附近有情况」——**一下捅穿迷雾**。

**解法:能否快走由玩家自己的警戒状态决定,不由真实敌情决定。**
派了斥候、设了岗、走的是熟路 → 敢加速;什么都没做也能加速,**那正是被突袭的原因**。
**风险归玩家,信息不白送。**

## 7. 魔物与恶魔:世界上的第三类活物

- 作为一类特殊 `WorldParty`:**不属任何势力**,行为逻辑另一套(游荡 / 守地 / 为血腥所引);
- 出现在行军路上、战场附近——**打完一仗留下的尸山,会把它们引来**(战场清扫的另一重理由);
- **绕开还是迎战,是玩家的行为,不是选择框**:你可以改道(费时费粮)、可以派一部去挡、
  可以趁夜潜行(疲惫+被发现风险)。系统只提供处境与代价。

## 8. 分步迁移路径(每步可玩、可收档——沿用宏观构想 §8 铁律)

| 步 | 内容 | 完成后的体验变化 |
|---|---|---|
| **1** | **就地展开**:遭遇不再切场景,在世界当前位置由 `WorldGen` 细采样生成战场,镜头拉近、时间降为实时 | 「两种模式」在体验上消失 |
| **2** | **世界不再静止**:接战期间远处队伍继续行动与互打 | 你打着仗,另一股虏骑正绕你侧后——**而你不知道,除非斥候告诉你**(本架构的灵魂) |
| **3** | **扎营完备度**驱动指挥通道开关;突袭 = 低完备度开战 | 准备本身成为玩法 |
| **4** | **行军日常**(斥候/巡岗/警戒/打扫战场),各配风险 | 古代行军的质感 |
| **5** | **魔物**作为第三类活物入世 | 世界不只有人 |

**第 2 步是分水岭**:做完它,这个游戏才真的是「一个活着的世界」,而不是「大地图 + 战斗关卡」。

## 9. 与旧文档的关系

- **蓝图 v0.2 §三(三层架构)**:战略层/战术层的**分离**假设由本文件取代;
  三种**尺度**依然存在(生涯 / 行军 / 接战),但它们是**同一张地图上的连续变焦**,不是三个场景。
- **双世界模型 · 四大支柱**:原样有效;支柱① 由 §3 强化,支柱③ 由 §4 强化。
- **宏观构想 v0.3**:L1–L4 的**内容分层**不变(开放边野→经营→势力→身份),
  本文件只改**承载它们的架构**。
- **魔导战争设定 v0.1**:主角亲征在无缝世界里更自然——飞起来就是真的飞起来,
  「沙盘停更」的代价照旧成立。
