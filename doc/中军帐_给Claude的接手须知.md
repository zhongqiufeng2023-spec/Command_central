## 1. 这游戏是什么(30 秒)
单机 PVE、冷兵器、古代战争**指挥官模拟**。你是中军帐里的孤独主帅,**永远没有上帝视角**,只靠**滞后/残缺/失真的情报 + 延迟的命令**指挥。**卖点不是打仗,是「看不见却要决断」。**
- **主题北极星**:**一将功成万骨枯**(隔着雾决人生死,功业堆在自己人的万骨上)。
- **基调**:表层荒诞/黑色幽默(Radio Commander 味)+ SAN 诡异压抑暗流;**深模拟在底、轻触感在上**;**可玩性 / 娱乐性 > 史实严谨(史实是佐料,不卡玩法)**。
- **参照**:Radio Commander、The Roottrees Are Dead(固定空间·实时信息处理)+《全面战争》式战后复盘。

3. **美术 / 视角**:旧文档多处写 3D 实景 + 第一人称 + 3D 兵海复盘;**现以本须知为准 = 全程 2D**——中军帐 = 2D 操纵将军 / 点工位(**无第一人称**),战场 / 复盘 = **2D 像素兵海(铁锈战争式)**。引擎仍 Godot,3D 场景封存当参考。
4. **战略层时间模型 + 基调**:旧文档写战略层「天数 / 回合制」;**现以本须知 / PRD §7 / 蓝图 §3.5 为准 = 战略层也是「连续实时可暂停」(骑砍式),全程一个时间模型,无「结束本日」**。且**可玩性 / 娱乐性 > 史实严谨**(史实降为佐料);战略层任务**非线性**(查粮草账目 / 选拔将领 / 接斥候军报 / 扎营 vs 夜行 / 改路线·定行军序列),**敌方 AI 升为「让玩法成立的支柱」,要用心**(见 PRD §9 / 蓝图 §十五)。
5. **玩家角色:主帅 → 全程副将(v2 大重构,覆盖旧「全程主帅」)**:玩家 = **一路副将**,**中军 = NPC**(发任务 / 可请援 / 隔着雾+政治评判你)。**旧文档所有「玩家=主帅 / 直辖 6–8 部队」一律改读为副将**。**术语**:玩家=副将;其麾下每队头目改称**武将 / 队将**(承接旧文「副将解读 / 副将回报」的角色)。**建军(骑砍式)**:≤8 队 × 每队 ≤250 人 × 每队配一名武将 × 六兵种混编(满编 ~2000)。**胜负=双层**:硬性=战略结局(该保的没崩 / 你部没覆没)+ 任务达成度评级(灵活多路径、不锁死胜负、非必全歼)。**政治赏罚**:主帅隔着雾+政治看你 →「赢不一定赏、输不一定罚」(评价 = 中军所知结果 × 遵命 × 代价 × 关系 × 运气,**不含真实功过**);**回报=塑造主帅认知的杠杆**(诚实/隐瞒/夸大各有风险);主帅有**性格**(重结果 / 重规矩 / 多疑 / 惜才…,你会先后跟不同主将)。MVP-轻:一条「主帅信任」+ 少量政治事件 + 2–3 主帅原型;完整层再多轴 + 生涯升迁(副将→更大命)。

## 4. 已锁定的决定(别再重新讨论)
- **设定 = 「大酆」· 唐基架空**:架空王朝大酆,以唐为底(唐式兵种/制度/美术皮)。主帅 = 受朝廷之命的**边镇主帅(节度使式)**;久镇拥兵 + 皇恩猜忌 → **造反线从安史式母体天然长出**;国号「酆」双关酆都冥府,暗合「一将功成万骨枯」。敌 = **多阵营**:人间(草原虏 / 藩镇 / 敌方副将)+ **超自然(冥府邪祟 / 祭冥神的邪教 / 妖魔;《战壕十字军》式 grimdark 披中式冥府皮,正应国号「酆=酆都」的暗面)**;打超自然 → SAN 掉得狠、诡异暗流转明,怪物 AI 另一套(潮水 / 不请援 / 恐惧扩散)。**MVP / 第一关仍人对人;超自然 = 完整层内容(怪物 AI / 恐惧 / bestiary / 新章节)**。兵种(已定·6):陌刀 / 枪槊 / 刀盾 / 弓弩 / 轻骑 / 具装重骑(部队=多兵种混编,克制在混编层)。**工程/攻城≠兵种**,= 扎营 / 攻守城时的情境选择(工匠+辎重+时间)。美术皮:明光铠 / 唐刀陌刀 / 团旗牙旗 / 中军大帐;旗鼓走唐式教旗金鼓。
- 全程**副将**视角,带**一路**:直辖 **≤8 队**(每队 ≤250 人、配一名**武将**、六兵种混编,满编 ~2000)。**中军 = NPC**(发任务 / 可请援 / 评判)。**武将 = 队级「解读层」**(第二层迷雾)。〔覆盖旧「全程主帅 / 6–8 部队」,见 §2 覆盖项 5〕
- **玩家坐镇 = 「本路中军帐」**(你阵线之后,有坐标、可前移、被攻破=危机);**两段延迟链**:帅帐↔你、你↔队;帐 = 令骑 / 斥候 / 旗鼓 / 瞭望 枢纽。之上是 NPC 主帅的帅帐。详见 `中军帐_关卡_第一关.md` §0。
- **实时** 20–30 分/局,从容;1 格≈50–100m + 部队按 km/h(接敌时间可心算)。
- 四信息渠道:**传令兵 / 斥候 / 旌旗金鼓 / 瞭望台**。旗鼓=绝对照令;副将解读偏差挂在传令兵意图上。
- **瞭望台 = 工位(2D,非第一人称)**:点瞭望台 → 切 **2D 战场俯瞰**(像素小兵)。**2D 表现「距离」= 清晰度随『离塔半径』衰减**(近清 / 中糊 / 远尘)× f(天气/地形/高地)——这是 2D 版「距离关系」的命门(顶视几何免费精确,故主动买模糊)。**实景转瞬即逝**(内核临时 `WatchtowerContact`,**不写 belief**);**手标**到沙盘才入 belief 并随后变旧。手标误差**按距离过渡(已定 · 丙)**:近处听你的(散布 ≈ 0)、远处系统撒点,`scatter=f(距离×天气×难度)`。呈现**纯顶视**即可(2.5D 斜俯视 = 后置可选)。也可俯瞰里直接发旗鼓。
- **失真双向**:情报回程 + 命令去程都会延迟/丢失/失真;可多轮冗余传令兵。
- 副将**主动回报 + 请示求决**(事件驱动)。
- **战斗 = 整体血量算 / 一堆小兵画**;**A 档**(部队级公式:混编克制+阵型/侧翼+士气/体力+崩溃连锁)先做,**B 档**(子部队位置 AI + 精密兵种 AI)后做。精锐(骑兵/骑射)近身可微操、投远入雾。
- **战前布阵 = 核心**(满控→失控的落差);MVP 做基础版。
- **复盘** = 忠实回放真相模拟(**2D 像素兵海,铁锈战争式**;原型简版即可)+ 道德清算「原来是我害的」。
- 敌方 = 对称迷雾 + Utility AI(性格=权重);AI「蠢得合理」即可——但**战略层改实时后,AI 升为「让玩法成立的支柱」,要用心**:敌将实时行军/扎营/撒斥候、截粮道、隘口设伏、佯动放疑兵。
- **战略层 = 骑砍式实时大地图(完整层)**:连续时间可暂停/调速、无「结束本日」;主帅做**非线性真决策**(查粮草账目〔账可能造假〕/ 选拔将领〔候选会吹牛〕/ 接斥候军报〔延迟矛盾有人味〕/ 扎营 vs 夜行 / 改路线·定行军序列);行军速度=f(构成×辎重×地形×天气×体力×模式),急行军更快但掉队+疲劳+只一部分能战。**可玩性 > 史实严谨,史实是佐料。**

## 5. 协作铁律(怎么和这个项目工作)
- **范围红线**:**MVP(一场看不清的战术战是否揪心)先行,内核不好玩全白搭**;完整层(战略/生涯/多轴失败/万人兵海/外交)= 多年多工种,单人首作**别一次做完**,更别塞进原型。
- **分工**:代码/架构/调试/教学 = 你(Claude)兜底;美术/音效 = 用户找免费资源(Quaternius/Kenney)/占位(单人真正瓶颈);决策/试玩/判断好不好玩/毅力 = 用户。
- **设计记录 ≠ 开工指令**:动手前先确认在 MVP 范围内。
- **检验任何新提案**:它服务于主题(功成↔万骨枯)吗?会破坏支柱①(给上帝视角)吗?
