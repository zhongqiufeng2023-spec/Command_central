## 一、已确认的基础决策
来自前序讨论(v0.1 §0.1)+ 本轮新增:
- 定位/目标/时间尺度/单机 PVE/冷兵器/战役+经营/难度调信息:见 v0.1 §0.1。
- **技术栈:C# 引擎无关内核**——纯 .NET 类库实现真相世界/认知世界/传令系统,配 xUnit 单测;里程碑二接 Godot(C#)时整块复用,零重写。落实 v0.1「内核与引擎彻底分离」的首要技术建议。
- **美术 / 视觉北极星**:原型期纯几何符号 / 棋子式标记。**战中**始终是抽象沙盘(只见认知世界);**复盘**是战场可视化。**抽象 ↔ 战场的反差**是核心呈现张力。〔**v1 更新(以此为准)**:全程 **2D**——中军帐 = 2D 操纵将军(**无第一人称**),战场 / 复盘 = **2D 像素兵海(铁锈战争式)**,不做 3D。详见 PRD / 接手须知。〕
- **设定(已定 · v1 新增)**:架空王朝**「大酆」· 唐基**(唐式兵种 / 制度 / 美术皮;娱乐 > 史实)。主帅 = 受命边镇主帅(节度使式)→ 久镇拥兵 + 皇恩猜忌 → **造反线天然(安史式)**;国号「酆」双关酆都冥府,暗合「一将功成万骨枯」。敌 = **多阵营**:人间(草原虏 / 藩镇 / 敌副将)+ **超自然(冥府邪祟 / 邪教 / 妖魔;战壕十字军式 × 中式冥府,应国号「酆=酆都」)**〔MVP 人对人,超自然=完整层〕;兵种 = 陌刀 / 枪槊 / 刀盾 / 弓弩 / 轻骑 / 具装重骑。

## 二、§9.2 待定问题的结论
- **局时长:20–30 分钟中局**(有战役感、情报层次更多;单局试错成本相应提高)。
- **读情报重度:轻量起步,难度解锁深度**——原型先做「轻点查看 + 信息年龄 + 幽灵标记」;把「主动交叉比对矛盾情报」作为高难度才浮现的硬核层,用难度旋钮调节(契合支柱④)。
- **叙事:轻叙事 / 沙盒**;「皇帝命将军征伐西北」充当免费叙事框,不做重剧情主角线。
- **失败惩罚:** 不再是简单惩罚,整个元层重构 —— 见第三、四节。

## 三、整体架构:三层(生涯 / 战略 / 战术)

### 3.1 三层架构总览
- **生涯层**:半线性将军生涯——多个大章节(战役)串成主线、关键处分支;核心元状态(声望 / 老兵 / 皇恩 / SAN)**跨章节延续**。
- **战略层**:章节内的大地图战役——**连续实时可暂停(骑砍式,非回合)**、多轴压力、完整对称迷雾。
- **战术层**:20–30 分钟实时可暂停的单场战斗,核心延迟情报体验。
- 三层都复用同一条「双世界(真相 / 认知)+ 延迟情报」主轴,只是尺度不同。

### 3.2 生涯层:半线性将军生涯(已定)
- 一条主线串起多个战役(如 平叛 → 远征西北 → 抵抗侵略…),关键处有**分支选择**。
- **核心元状态跨章节延续**:声望、老兵(幸存并成长的部队)、**将领班子(见第十节)**、皇恩、SAN —— 胜败有长期回响,像一位主帅的一生。
- 失败系统的「造反」结局在此有天然归宿:可**把整条生涯分叉到反贼路线**。
- **终局处理(已定)**:随时可读档;终局可读回继续,或选择重新开局。"重量"来自过程中的动态后果(老兵折损 / 局势恶化 / 多结局演出),而非一败到底的硬惩罚。
- **章节间(已定)**:设「班师受赏 / 休整」喘息节点,SAN / 皇恩**部分恢复**,防止生涯死亡螺旋。

### 3.3 章节层:大章节(战役)anthology(已定)
- 每个大章节是自成一体的战略场景,**共用同一套战略引擎**(节点图 + 双世界 + 多轴压力),只换地图 / 目标 / 起始态势 / 敌将 / 主打战斗形态。
- 章节类型(对应历史战争类型,示例):
  - **远征开疆**(如征伐西北):长粮道、纵深推进 → 主打 遭遇 / 攻城
  - **平定叛乱**:内部、敌我难辨、信息混乱 → 主打 遭遇 / 突袭 / 夜袭
  - **征讨逆贼**:追击流动叛军 → 主打 突袭 / 遭遇 / 包围
  - **抵抗侵略**:分两阶段「守城 → 反攻」(章节内阶段弧线)→ 主打 守城 / 突围 / 攻城
- **给 v0.1 §4.3 七种战斗形态一个归宿**:它们 = 每个章节主打哪几种,而非散落模式。

### 3.4 将军视角与动态战略(核心 philosophy)
- 你是皇帝麾下的将军,领受一个章节的战略目标。
- 战斗惨败**不重来** → 变成新的战略处境:等后援 / 招兵 / 换战术继续推进同一目标。
- **时间即代价**:你花的每一天敌人也在用 → 战略层是第四节多轴压力的"时钟"。

### 3.5 时间模型:全程实时可暂停(已定 · v1 改:原回合制作废)
- **战略层与战术层同一时间模型** = **连续实时,可暂停 / 0.5 / 1 / 2 / 4x**(骑马与砍杀战役地图式)。**取消「结束本日」**;休整 / 招兵 / 等斥候 = 原地驻留 + 快进。你和敌军都是地图上**实时在走**的队伍。
- **「时间即代价」实时化**:五轴(粮草 / 经费 / 皇恩 / SAN / 士气)按时间连续消耗;皇恩催战 = 地图上**看得见的倒计时**实时逼近。比每日扣格更揪心。
- **行军规则(史为佐料,玩法优先)**:速度 = f(部队构成 × 辎重 × 地形 × 天气 × 体力士气 × 行军模式)。基准常行军 ≈ 30 里 / 日(一舍);**急行军(倍道)更快,但掉队 + 疲劳 + 到达时只有一部分成建制可战**(把孙子《军争篇》「十一而至 / 半至」做成机制)。大军更慢、纵队有长度、过隘口 / 渡口慢且脆(夜袭高发);可弃辎重换速度 = 「委军争利」的豪赌。
- 战术内核仍是**纯函数**「战场状态 → 战斗结果」,战略层实时调用它;两层解耦、可独立单测。

### 3.6 战略地图 + 主帅任务 = 真决策(已定 · v1 改)
- **地图**:节点-连线为骨,但队伍在边上**实时行军**(不瞬移)。节点:大本营(援军/粮草源)· 城(目标)· 关隘(咽喉)· 渡口(脆弱,夜袭高发)· 村镇(掠夺/征粮)。边:地形 / 是否粮道 / 隘险。规模:完整版约 8–15 节点;垂直切片 3–5 节点。
- **主帅任务 = 非线性的真决策**(随时在帐中 / 马上做,不是照流程走):
  1. **查粮草账目**:翻粮官的账本——可能被克扣 / 做假,**连你自己的补给数都未必真**(迷雾渗进自家帐)。
  2. **选拔将领**:从有性格、有故事(也可能吹牛 / 有毛病)的候选里提拔、编入部队——是赌。
  3. **接斥候军报**:延迟、可能矛盾、措辞有人味(慌张 / 夸大 / 错字)的情报陆续送到。
  4. **决定扎营 / 夜行**:天黑前择营(高地近水可守)vs 趁夜赶路(快但疲、易遭夜袭、士气 / SAN↓)。
  5. **改路线 / 定行军序列**:绕威胁、换地形、调前锋 / 中军 / 后卫 / 辎重次序、护粮道、撒游骑屏蔽。
- **娱乐性优先**:以上系统尽量有人味、有黑色幽默(贪墨的粮官、慌张小兵的军报、爱吹牛的候选将);**史实是佐料和灵感,不是模拟枷锁**,卡玩法的真实一律让路。

### 3.7 战略层 = 完整对称迷雾(已定)
- 战略图敌情也是"最后已知";靠**斥候**(战略层的传令兵)带回延迟 + 失真的战略情报;敌人也看不清你。
- 落实 v0.1 §5.2「把信息变成可经营资源」:投资斥候网 → 战略图更清。核心双世界模型在战略层**复用一次**。

### 3.8 敌人在实时地图上(已定,全选)—— 决策有意义全靠它
- 敌将也在**实时行军 / 扎营 / 撒斥候**,有自己的认知世界与目标。威胁:增援变强 · 切断粮道 · 隘口渡口设伏 · 夜袭脆弱点(→ 触发你信息最差的战术战)· 佯动放疑兵污染你认知(需多源交叉验证识破)。
- **关键**:战略层不再是线性流程,而是**和这个实时对手互动出来的决策空间**——你每个「扎营 / 改路线 / 撒斥候 / 弃辎重」都因为对面会反应才有意义。**所以敌方 AI 必须用心设计(见 §十五)。**

### 3.9 范围
全部属完整层。原型不做战略层与生涯层,但战术内核预留纯函数接口供将来调用。

## 四、多轴压力 / 多结局失败系统(已细化)

### 4.1 结构:5 主轴 + 派生评估值
- **主轴**(0–100,是"因"):士气 / 粮草 / 经费 / 皇恩(期望与耐心)/ SAN(心智)。
- **累积计数器**:伤亡(不是条,是不断喂给其他轴的"毒")。
- **综合评估值 = 派生仪表盘**(战局评估:危殆/艰难/稳健/优势)。作用:总览显示 + 影响皇帝态度(评估越低,皇帝越易催战/召回)+ 复盘评分。
- **结局由"哪条主轴先被击穿"决定**(各轴独立触发各自的结局),评估值本身只是预警表。↑ 这条已确认。

### 4.2 压力网(主轴互相喂养 → "越拖越难"自然涌现)
- 伤亡 → SAN↓、士气↓、经费↓(抚恤)
- 粮道被断 → 粮草↓ → 士气↓
- 久拖不胜 → 皇恩↓ → 催战诏书/威胁 → SAN↓
- 经费↓ → 发不出犒赏、招不到兵 → 士气↓
- **SAN↓ → 认知世界可信度↓ → 误判 → 更多伤亡(死亡螺旋)**
- 掠夺 → 钱粮↑ 但 民心↓ → 敌方抵抗↑ + 皇恩↓

→ 你要的"敌人动态升级"压力从这张网**自然长出**,无需脚本硬编强化敌人。

### 4.3 各轴 击穿 → 危机 → 挽回/结局(两段式,留挽回余地)
| 轴 | 击穿危机 | 挽回 / 结局 |
|---|---|---|
| 士气 | **哗变**(内部战术战) | 哗变情报是迷雾的 → 甄别叛部 → 集结忠诚部队 → 平叛;胜则士气部分恢复,败则瓦解终局 |
| 粮草/经费 | 抉择 | **掠夺**(民心↓/皇恩↓/抵抗↑) or **班师**(目标受挫/皇恩↓) |
| 皇恩 | **召你回朝** | **造反**(替代战役线,完整层 stretch) or 回朝迎接降罪结局 |
| SAN | **疯了 / 自杀**(终局) | 见 4.5 回血 |

### 4.4 经费 vs 粮草:分开两条(已定)
- **粮草**:持续后勤,逐日消耗,粮道被断则加速见底 → 崩士气。
- **经费**:可支配国库,招兵/犒赏/升级;掠夺/班师抉择主要挂在钱粮危机上。

### 4.5 SAN 设计(已定)
- **低落表现 = 绑定迷雾**:SAN↓ → 认知世界更不可信(假标记、夸大战报、命令延迟变长、副将更易误解)。SAN 与核心迷雾母题**双向绑定**——心态崩了,你眼里的战场就更假。
- **回血来源**(难涨易跌,每种花时间或资源):
  1. 胜利 / 捷报
  2. 安全驻扎 / 休整(消耗天数)
  3. 家书 / 幕僚 / 祭祀(消耗一个行动)
  4. 稳定清晰的情报(连续一致情报回稳;长期信息黑暗持续掉 SAN)
  - (候选未定:皇恩犒赏 / 加官进爵)

### 4.6 设计价值(为何这套系统成立)
1. **哗变信息也要侦察** → 迷雾延伸到军帐内部,连"自己人要反"都是滞后/残缺情报。
2. **SAN** → 把主帅本人变成要管理的资源,契合"孤独主帅困于中军帐"母题。
3. **哗变 = 内部战斗** → 复用同一套战术引擎 + 迷雾,架构上近乎零额外成本。

### 4.7 范围
全部属完整层。原型唯一可早期试水:**SAN↓→信息失真**(复用认知世界失真管线、增强核心体验),仍为 nice-to-have,非原型必需。

## 八、自洽性检验(一切是否服务于支柱① 迷雾即灵魂)
- **战术层**:延迟 / 残缺 / 失真情报 = 灵魂本体。
- **战略层**:对称迷雾 + 斥候 → 把"看不清"扩到战略尺度;v0.1「把信息变经营资源」落地。
- **失败系统**:SAN↓→信息更假,把主帅心态并入迷雾;哗变情报同样要侦察 → 迷雾进军帐内部。
- **生涯层**:延续状态让"看不清导致的损失"有长期回响(老兵之痛)。
- **难度**:全程用"信息丰度"当旋钮(信息为主 + 少量数值),贯穿支柱④。
→ 每一层都在强化信息不对称,无一处给上帝视角。**设计自洽**。

## 九、战术核心玩法(原型 · 已定)

- **控制单位 = 队(非士兵)**〔v2:玩家=**副将带一路**,直辖 **≤8 队**(每队 ≤250、配武将、六兵种混编,~2000);中军=NPC。覆盖旧「每方 3–4 支 / 主帅」〕。属性(真相):位置 / 兵力 / 兵种 / 士气 / 体力 / 当前意图。沙盘只显「最后已知」+ 信息年龄。
- **核心循环**:读滞后战报 → 拼图 → 下意图 → 延迟送达 → 副将按「送达那刻的真实情况」解读执行 → 结果 → 战报延迟送回 → 看到过期结果 → 调整。
- **下意图 = 结构化动词 + 基调**:选部队 + 动词(移动 / 攻击 / 据守 / 后撤)+ 目标 + 基调(谨慎 / 常规 / 激进 / 不惜代价 / 见机行事)。基调是给副将解读留的空间。
- **副将解读 = 第二层迷雾**:每部队一名带性格副将,性格驱动解读;原型只做轻量(性格影响激进/谨慎 + 情况变化时临机改判)。完整养成见第十节。
- **战斗结算**:抽象 attrition,损耗 = f(兵种克制 × 地形 × 士气 × 体力 × 随机);三角:枪克骑 / 骑克弓散 / 弓克步 / 盾抗远程。士气、体力为隐藏关键值(崩则溃逃 / 竭则战力打折)。
- **战报产生(部队 = 传感器)**:每支部队维护**自己的局部敌情记忆**;传令兵把「**自身近况 + 该部队所知的全部敌情**(各带各自的观测时刻)」**打包**送回。所以一支久未通信的部队,其传令兵抵达时会一次性吐出它所知(可能已严重滞后)的整张局部敌情图。玩家主动派传令兵**探问**某部队,返回的就是它的完整局部情报包(接第十二节)。途中可被拦截 → 丢失。
- **视野与斥候(侦察)**:部队 / 传令兵 / 斥候各有自己的视野(**斥候 > 部队 > 传令兵**)。**等待时**部队按将领性格自发派斥候拓展视野(激进探得远、谨慎勤而近、善诈偏侧翼);中军可直接派斥候,或经传令兵令某部队派斥候到指定点。斥候速度介于部队与传令兵之间,**避敌绕道、不靠近**,到点或受阻即返回:部队派的汇报给部队(再经传令兵转呈中军、二段延迟),中军派的直接更新认知世界。传令兵途中也以自身小视野顺带带回所见。
- **指挥通道(旗鼓 · 已落地内核)**:除传令兵外,中军帐可用**旌旗(视觉,需通视)/ 金鼓(听觉,需在声程)**发令——近即时、带宽低(只传 进/守/退/集结)、复用视野·地形·天气门槛(雾夜砍半、林地阻声),边缘能见度差会**误读**;**且会被视线/声程内的敌军读到**(军令泄露 → 落地 §十二 佯动)。三通道互补:**传令兵**=高带宽·慢·私密·可被拦截;**旗鼓**=低带宽·快·公开·受能见度限。「部队离中军近→旗鼓即时,推进到远处→只能靠传令兵」自然涌现。出处《孙子·军争》「言不相闻,故为金鼓;视不相见,故为旌旗;夫金鼓旌旗者,所以一人之耳目也」。
- **瞭望台(高处观察 · 已落地内核)**:中军帐近处的**实时、低保真**直接观察——位置 + 规模档(烟尘 大/中/小),**不给精确兵力/兵种**,只覆盖视野半径(**看得见烟尘 > 够得着号令**),雾夜林压缩。它**不写入认知世界**,而是每 tick 重算的「烟尘印象」叠加层,与延迟战报标记**并存**——补上「此刻·眼前·却看不真切」这唯一缺口,又不破支柱①(望楼也只看近处、看不真切;上帝视角仍只在战后复盘)。三维里 = **登台远眺**(扬尘/旗帜/影绰团块) ↔ **低头看沙盘**(延迟认知)的战时反差。
- **信息渠道总览(古代战场感知系统)**:① 传令兵 ② 瞭望台(高处观察) ③ 旌旗金鼓 ④ 斥候 —— 均已落地内核;⑤ 多级层层汇报 ⑥ 审俘/间谍 ⑦ 烽火狼烟 ⑧ 军师幕僚汇总 —— 完整层。每条 = 真相→认知的一根「管道」,各有 延迟 / 带宽 / 可靠 / 触达 / 泄密 的不同组合,信息随距离自然衰减。
- **时间**:实时可暂停;暂停可读情报/思考,下命令受限(避免暂停变作弊键)。
- **一局结束(v2:任务制)**:胜负 = 双层——硬性=战略结局(该保的没崩 / 你部没覆没)+ 任务达成度评级(灵活多路径、喂政治赏罚)、**非必全歼**。20–30 分钟靠地图与行军速度调。

## 十、将领养成系统(伙伴 / 指挥班子)

- **定位**:完整层 meta 系统;原型只需「带性格副将」。
- **将领属性(已定,全选)**:
  - **性格**(激进/谨慎/善诈/稳健…)—— 驱动解读意图的方式,第二层迷雾核心。
  - **统率 / 能力** —— 执行质量、带兵上限、稳住士气。
  - **兵种专长**(善骑/善守/善奇袭/善弩)—— 适合统领哪种部队。
  - **背景 + 忠诚 + 年龄** —— 出身故事、与你渊源、忠诚倾向(→ 叛变/自作主张)、会老去/伤病。
- **来源**:从小队长 / 百户提拔;战斗胜利后表现突出者「涌现」为可提拔对象,自带背景故事。
- **玩家行为**:提拔、编入部队、派去特殊任务(斥候/断粮/平叛/策反,接战略层)、培养一套用熟的指挥班子。
- **与核心迷雾的咬合(已定,核心机制)**:
  1. 将领性格 = 第二层迷雾引擎(同一意图,不同将不同执行)。
  2. **熟悉度降低迷雾**:用熟的班子可预测 → 迷雾小;陌生将 → 迷雾大。养成 = 对核心迷雾的杠杆。
  3. **将领之痛**:将领跨章节延续(同老兵);依赖的将阵亡/叛变 → 失去可预测性 → 迷雾骤增。情感 + 机制双重重量。

## 十一、情报失真四类机制(已定)

- **统一管线**:每份战报生成时掷出「延迟 / 完整度 / 可信度」,因子 = 距离 × 天气·昼夜 × 观察者侦察技能 × 观察者士气(惊慌) × 敌方善诈 × **你的 SAN** × 难度。四类失真都从这条管线出。
- **延迟**:所有情报的基础属性;呈现为「信息年龄:X 前」+ 超时未更新褪色为半透明**幽灵**。
- **丢失(已定:纯沉默)**:传令兵被拦截/阵亡 → 情报永不达,且**不给任何提示**(你甚至不知道本该有消息)。最纯粹的迷雾。〔减负候选留给难度:低难度可对「主动派出的传令兵未归」给提示。〕
- **残缺**:标记带「?」字段(兵力不明/兵种不明/方向模糊)。
- **失真**:看似言之凿凿却是错的(小兵惊慌夸大、敌方善诈放假情报、**SAN 低自己脑补**)。**可信度提示 = 难度调**:低难度给显式「可靠/存疑」标,高难度拿掉、只能多源交叉比对。
- **矛盾情报并存** = 拼图式认知的操作本体(不同时刻两份战报可同屏并存,你自己判断)。
- **复盘是安全垫**:纯沉默 + 无提示很硬核,靠**战后复盘揭示真相全貌**兑现「原来如此」的顿悟与学习,化解挫败。

## 十二、等待期决策(支柱③ 等待是玩法 · 已定)

- **核心张力**:你等的时候真相世界在动 → 每个空窗 = 「再等一份情报 vs 现在就赌」。
- **传令兵 / 斥候 = 难度调资源**:低难度宽裕,高难度吝啬,逼你取舍「派谁去问哪个方向」。
- **暂停语义**:暂停可读情报、可排队意图,不可即时下令;意图恢复后才随传令兵出发(防作弊)。
- **动作集(已定)**:
  - 投入 / 回撤**预备队**(招牌决策;预备队也有行军延迟 → 赌时机)
  - 派传令兵向某部队**索要近况**(往返延迟;可能纯沉默)
  - 补派 / 调整**斥候侦察方向**(把侦察投到最担心的区域)
  - **排队条件命令**(「若…则…」)+ 给在途传令兵**派护卫**(降被拦截)
  - **佯动 / 设疑兵**:主动给敌人放假情报 / 造势,**污染敌方认知世界**——第一次从"被迷雾困"变"用迷雾打人"。复用同一条失真管线(方向反过来),需敌方 belief world(已设计的对称迷雾 AI)。
  - **审讯俘虏 / 招降**:又一情报源,天然可能假 / 过时。
  - **巡营安抚 / 军议**:提士气、压 SAN、与幕僚推演敌情(接 4.5 SAN 回血)。
  - **派死士 / 间谍策反敌将**:高风险高回报(接将领特殊任务系统)。
- **范围**:原型期做前 4 项 + 简化佯动;审讯 / 策反 / 死士 / 军议属完整层。

## 十三、难度旋钮(支柱④ · 已定)

- **形态**:**预设档**(如 轻松 / 普通 / 硬核 / 地狱),一键设定整个参数向量;不做自定义滑块。
- **原则**:**信息为主 + 少量数值**——难度主要靠调「信息丰度」,允许高难度略微上调敌方兵力 / 补给等数值作补充(但信息仍是主要杠杆,守住支柱④主旨)。
- **旋钮控制的参数向量**:
  - **你方**:情报延迟 · 丢失率 · 残缺率 · 失真率 · 可信度提示有无 · 传令兵/斥候数量 · SAN 衰减速率 · 丢失「未归」提示有无 · 免费基线信息量(地形/初始敌情)。
  - **敌方**:侦察范围/精度 · 敌方情报延迟 · 敌方 AI 决策质量 ·(少量)兵力/补给数值。
- 低难度 ≈ 「信息充足」模式,兼当**新手教学**(v0.1 §8.4)。

## 十四、复盘系统(战后回放 · 已定)

- **三个目的**:① 兑现「原来如此」顿悟;② 学习闭环(看懂漏了什么 → 更会读迷雾);③ 给硬核迷雾(纯沉默 / 高难无提示)兜底,把挫败转成理解。
- **核心 = 认知 vs 真相 对照回放(已定:完整回放 + 关键标注)**:
  - 时间轴可拖动回放(真相视角:双方所有部队真实走位)。
  - 认知 / 真相并排或叠加,**自动标出关键分叉点**(「T+12 你以为敌在桥头,实际已渡河 15 分钟」)。
  - 关键决策回顾:在哪个(过期 / 错误)情报下下了哪道命令、结果如何。
- **揭示范围(已定:全图真相)**:揭开整张图真相(含从未侦察到处)。上帝视角只在战后给,不破坏战中迷雾。
- **呈现风格(已定:仅复盘)**:复盘用《全面战争》式战场可视化(部队在战场上移动、可见单位);战中保持抽象沙盘。**抽象 → 电影感的反差**正是顿悟的载体。允许低模 + 简单动画(完整层 / Godot,非原型)。
- **复盘评分 / 统计**(接 §4.1):平均情报时效、丢失情报数、基于错误情报的误判决策数。
- **结算产出**:战功 → 干部涌现(§十)、捷报式 SAN 回血(§4.5)。
- **原型实现(已落地)**:控制台 `replay` 命令**逐 tick 上帝视角动画回放**。战中隐藏斥候 / 传令兵位置(你没有自家侦察兵的实时坐标,派出去只能等回报),**复盘才以 `*`(传令兵)/ `o`(斥候)显形**,并显形敌方斥候 `x`——强化「战时看不见、战后才看清」的反差。

## 十五、敌方 AI(已定 · v1 加重)——「战略层是不是真决策,全看它」

- **为何要用心(v1)**:战略层改实时、非线性后,**没有会反应的对手,地图就是空跑**;AI 用心,你每个扎营 / 改路线 / 撒斥候才有回应。敌方 AI 从「配角」升为**让玩法成立的支柱**。
- **地基 = 对称迷雾**:敌方有自己的认知世界 / 迷雾 / 传令延迟,基于不完全信息决策 → 合理行为自然涌现、可被利用盲区奇袭、难度由信息量调。
- **决策架构(已定:混合)**:战术层用 **Utility AI**(候选行动按「敌方认知下收益」打分选最高,轻、好调、能表达权衡);完整层在战略层叠 **GOAP** 串多步计谋(诱敌深入 → 断粮 → 围歼)。
- **战略行为库(实时地图上)**:抢占目标 · 截你粮道 · 隘口 / 渡口设伏 · 夜袭你脆弱点 · 佯动放疑兵污染你认知 · 势弱避战 / 势强寻战 · 骚扰你纵队 · 坚壁清野。敌将也实时行军 / 扎营 / 派斥候。
- **性格 = 效用权重向量**:激进 / 谨慎 / 善诈 / 稳健 / **贪功 / 吝啬** = 不同权重;行为从权重涌现,改权重即改性格,零脚本。支持 §十「识破并利用敌将」。
- **「蠢得合理」是特色非缺陷**:不求神,求**可信 + 会反应 + 有性格**;失误是可爱、可被你抓的破绽(参《桌上谈兵》「把权重调对就够」)。**娱乐性优先**:宁可敌将偶尔上头犯傻(贪功冒进、疑神疑鬼),也不要冷冰冰的最优解。
- **敌将性格可知度(已定)**:开局简报给**可能不准的估计**(v0.1 §3.2),善诈者尤易被误标——「敌将是谁」也是迷雾的一部分。
- **能力档 = 难度调**:调敌方「看多清 / 想多准 / 延迟多短」,不灌数值(§十三)。
- **复杂度**:单位行为可低保真,简单动作即可(呼应「大量单位 × 简单行为」的全战式取向)。

## 十七、天气 / 地形(已定)

- **双重作用(已定:信息与战斗并重)**:既调侦察 / 传令 / 迷雾,也改移动 / 兵种 / 战力。其中"信息效应"是本作区别于普通战争游戏之处。
- **地形**:山地 / 林地 / 河流 / 隘口 / 平原 / 城墙 → 移动速度、视野 / 侦察、兵种效能(骑忌林 / 城)、传令兵行进与被拦截。
- **天气**:晴 / 雨 / 雾 / 雪 / 夜 → 侦察距离(雾夜大幅压缩)、行军、弓弩、士气。
- **天气动态(已定:由章节 / 难度决定)**:不在局内随机变,而是章节 / 难度设定的固定条件(夜袭章节恒夜、某战役多雾…),与 §3.3 章节类型挂钩。
- **原型子集**:平原 / 林地 / 河流 + 晴 / 雾 / 夜。

## 十八、战术层:实时 + 中军帐实景(单空间 · 道具 · 信息处理)

- **类型北极星**:固定空间实时信息处理(《鲁特里一家》《无线电指挥官》的古战版)。**时间持续流逝,可暂停 / 减速 / 加速**;每部队各自速度(权重计)。修正原「步进」近似。
- **中军帐 = 单一空间多工位**:沙盘(认知世界主视图)· 令旗竹筒(取令旗下令)· 瞭望台(登台远望)· 情报案(最新战报纸)。对应支柱②。
- **道具交互**:取斥候令旗掷向沙盘某点 → 斥候出发;旗鼓在友军可视/声程内即时(持续擂鼓 = 持续前进,细节后补);远距用传令兵(延迟),指令含**阵型(默认副将定)/ 行进速度**;传令兵回程带回该部队 **士气 / 位置 / 所见敌情**。
- **斥候回报**:位置 / 兵种 / 规模 / **方向 / 速度**(→ 玩家据此估「接敌时间」)。
- **瞭望台 = 玩家主动工位(非被动常开)**:敌入台视野 → **小兵来报** → 玩家可前往,看实际方位、估距,**亦可在台上掷旗**(如招部队回防)。代价 = 实时照流 + 离开沙盘案(而非「不能下令」)。〔v1 更新:全程 **2D 顶视**;「距离」= **清晰度随『离塔半径』衰减**(近清/中糊/远尘);手标散布 scatter=f(距离),近 ≈ 0 / 远靠系统(**丙**)。详见 PRD §6.3 / §6.4。〕

## 十九、完整游戏循环(完整层概览,落 §三 三层架构)

大地图(战略级)行军 / 补给线 / 征兵买马 / **部队自由编制与命名**(前锋·左右翼·中军·守军·预备·后备)与副将提拔 → 发现敌军:追击 / 守城 / 攻城 → 接触:劝降 / 骂阵(按程度给 buff·debuff) → 战前布阵 · 临阵换将 → 进入战术战(§十八) → 战后:胜负分级(大胜 / 势均 / 险胜 / 惨胜)与 追击·包围·打扫·整备 / 或 断后·突围·投降(依敌方 AI) → 回大地图循环。**均属战略层 + 生涯层(完整层),原型不做。**
