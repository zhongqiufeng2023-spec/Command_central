# 《中军帐》魔导战争设定 v0.1 —— 冷兵器时代的《幼女战记》

> **性质**:设计记录 ≠ 开工指令(项目铁律)。本文件固化 2026-07-11 用户口述的**魔导层**构想,
> 覆盖战术层(术士队 / 主角亲征 / 主帅存亡)与完整层(威望 / 俘虏 / 传承 / 各方国策)。
> **战术层双世界内核一字不动**——魔导是长在它上面的,不是绕过它的。
> 配套:`中军帐_宏观战略构想_v0.3.md`(活的乱世)· `中军帐_MVP实现计划.md`(路线与存档点)。

## 1. 一句话

**冷兵器时代的《幼女战记》**:玩家是一个拥有超量魔力的将军——
他一人可以在一片天空里所向披靡,却永远无法凭一己之力扭转一场会战。
**而这个上限不是系统写死的,是玩家自己的取舍换来的。**

主题句:**魔法赢得战斗,输掉战争的仍是粮草与朝堂。**

## 2. 三条铁律(任何魔导相关设计的自洽性检验)

1. **强而不能定乾坤**——一人之力足以击溃一部,不足以决定一场会战。
2. **只设代价,不设禁令**——绝不写「魔法不能赢」这种规则。只写弹药有限、占不住地、
   溃可复聚、离帐即聋、敌有反制、用之伤神。玩家若操作到极致而赢下不该赢的仗,**那是他挣来的**。
3. **限制来自操作与取舍**——上限由机会成本构成,不由数值阈值构成。

## 3. 魔力设定:术式是技术,力量源自幽冥

- **术式 = 可研究、可传授、可禁绝的学问**。所以各方势力对它有**国策之争**(见 §8),
  也所以「培养」是真实的:天赋者本就稀少,还要慢慢练。
- **力量之源 = 幽冥之气**。用得越多,离人越远——直接喂现有的 **SAN(心神)** 轴:
  施术耗神 → 心神低 → 回报误差放大、沙盘长出根本不存在的敌军。
  **力量在腐蚀你赖以指挥的那个器官。** 与国号「酆」(双关酆都)、与冥府邪教线天然咬合。
- **主角的「超量」= 不可复制的天赋**,不是等级也不是装备。后继者永远达不到(见 §7)。

## 4. 术士队(魔导部队):与六兵种并列的第七种

| 项 | 规格 |
|---|---|
| 编制 | 10–30 人(远小于常规部队的 160–250) |
| 机动 | 飞行,**无视地形**,速度略快于轻骑 |
| 攻击 | 术式炮击,**面杀伤**——对密集阵型毁灭性,对散开的队伍收益骤降 |
| 弹药 | 术式载荷有限(一战 6–12 发),**战中不回复**,战后按天恢复 |
| 生存 | 极脆(人少),弩阵齐射 / 敌术士可迅速打垮 |
| 撤离 | 只要敌方无同等力量,**永远跑得掉**——打不赢,也死不了 |
| 培养 | 天赋者稀少;新手 → 熟手需时间与战场经验(经营层内容) |

**大地图显示**:术士队人少,不适用「兵形 50:1」——单列显示规则(个位数小人 + 可辨识的标记)。

### 4.1 各势力术士装备:形制不同 = 情报

**装备差异不是装饰,是信息设计**——与「兵形 50:1 让你一眼看出大队还是游哨」同一种设计:
战场上瞥见一个飞行单位的轮廓,就该认出**是哪一方的、大概什么路数**。

| 势力 | 形制 | 一眼可读的信息 |
|---|---|---|
| 大酆 · 术士监 | 绯袍法冠、官制符牌 | 官军编制,炮击路数,受监临 |
| 草原 | 骨饰兽皮、羽旌 | 萨满一路——不炮击,防天候/惊马/咒诅 |
| 东北藩镇 | 杂色拼凑、雇佣旗号 | 募来的,忠诚可疑,遇挫易散 |
| 邪教 / 冥府 | 骨面、幽光 | 最怪的那一路,SAN 掉得最狠 |
| 禁术势力 | **无术士,只有对空弩阵** | 你的炮击在这里收益腰斩 |

**美术产出方式(既定决策)**:各势力装备由作者亲手把关,可用 AI 图像生成**在工具链中**批量出稿,
再作为普通资源打包——**不做运行时的玩家上传生成**(理由见宏观构想 v0.3 §8「美术与变现的既定决策」)。
玩家表达用**部件组合**(冠/袍/披风/法器/纹章 × 可调配色),全在作者画风内。

## 5. 主角亲征:用「全局的耳目」换「一处的眼睛」

**这是让「强而不能定乾坤」自己长出来的核心机制。**

战中任意时刻可自中军帐**亲身出阵**。

**你得到**
- 眼下这一片是**真的、实时的**(不再是滞后二十秒的军报);
- 目视范围内的部队可**当面下令**——不走令骑、不失真、不经武将解读。

**你失去**
- **沙盘停更**:塘骑回报、各部军报、副将请示统统送到一座空帐,回帐才一次性读到;
- **各部无令自处**:现有「请示求决」机制照常运转——耐性耗尽后,武将按各自性格自行其是
  (贪功的压上去,持重的钉住不动)。战线在你够不着的地方慢慢烂掉;
- **主帅位置泄露**:你在天上,全场敌军都知道主帅在哪(与旗鼓的「军令泄露」同源);
- **心神耗蚀**:施术掉 SAN,回帐后你收到的一切更不可信。

> **视角契约(支柱①不破)**:迷雾没有被打破,只是换了位置——
> 你用一张宽而旧的二手图,换了一片窄而真的一手视野。**任何时刻都不存在全图上帝视角。**

## 6. 主帅存亡:不是判定,是战场上最紧张的一分钟

**用户定调(2026-07-11):主帅倒下不做结果判定,做实时演算的抢夺。**

### 6.1 坠地即争夺
- 主角被弩阵射落 / 被敌术士击败 → 成为战场上一个**不能动的实体**(有生命计时);
- **双方 AI 皆以最高优先级扑向此处**:敌方要抢活的,我方要抢回来;
- **术士卫队**(亲卫)因会飞,多半最先抵达——但敌方也有他们的。

### 6.2 部队的反应 = 一面镜子
救不救、拼不拼命,由 **威望**(§6.4)与**治军方针**决定,不由脚本决定:
- 高威望 → 附近各部**不待令自发扑救**(甚至违抗你此前的命令);
- 低威望 → 有的观望,有的直接崩("主帅都完了")。

### 6.3 三种去向,皆有后续
- **抢回**:重创昏迷退场——战中不能再出阵、不能视事(沙盘冻结更久),SAN 大损,战后养伤数日;
- **被俘**:敌方押你回本阵——**押送途中仍可被拦截救回**(与令骑可被截杀同一套物理);
- **战死**:**尸身在谁手里也是一场仗**——夺回遗体厚葬,或任其落入敌手。

### 6.4 威望(新增轴)——与主帅信任必须能背离
| | 看你的人 | 已有/新增 |
|---|---|---|
| **主帅信任** | 朝廷、上级 | 已有(`Trust`) |
| **威望** | 你自己的兵 | **新增** |

- **喂养**:万骨账(`Bones`,已在记)——**你踩着的骨头越多,他们越不肯为你去死**;
  是否与士卒同甘(断粮时谁先饿)、是否救过他们(驰援)、是否兑现赏赐(军饷,经营层)、胜负。
- **治军方针**(可切换,各有代价,直接接现有的命令失真系统):
  - *严刑峻法* → 令行禁止、解读偏差小;但你倒下时没人肯为你送命;
  - *宽仁厚赏* → 威望高、救主拼命;但纪律松、命令走样大;
  - *唯功是举* → 悍将效死、庸者离心。
- **两轴背离 = 军阀化的土壤**:兵爱你、朝廷疑你——L4「身份自由」不需另行设计,它自己长出来。

### 6.5 被俘期间:不是等待画面,是迷雾的纯粹形态
- **你彻底瞎了**:只能听见零星传闻——这恰是支柱①最纯粹的样子;
- **但你在敌营里**:能看见别人一辈子看不到的东西(虏军虚实、将领、军议)。
  **逃回或赎回的你,带着一份任何塘骑都换不来的情报**——惩罚变成处境;
- 你的部队进入 **AI 托管**(可复用大地图 `WorldParty` 容器,变成边野上的一支 NPC 队伍);
- **是否有人来救你**,取决于:你与部下/接任将军的关系(威望)、你对朝廷的价值(信任+功业)。
  重要则组织营救或政治赎回;不重要,就烂在那里。
- ⚠**待设计**:被俘期玩家的实际操作面(不能是纯过场)。

### 6.6 传承:骑砍式的「子嗣继续」,不是换个存档接着玩

**用户定调:参照《骑马与砍杀》的子嗣继承——你死了,你这一脉继续下去。**
关键差别:**继承的不是存档,是你留下的班底与关系。**

- **继承者在你活着时就已存在并成长**,不是死了才生成:
  - **子嗣**——有血脉,但**魔力天赋不保证遗传**(术式是可学的技术,「超量」是个人的天赋);
  - **亲传弟子 / 部下军官**——无血脉,但有履历(王朗、何武、周石、李彀、秦锐、呼延豹……
    本就各有性格与能力值)。
  - **你活着的每一个选择,都在决定他接手的是什么**:带不带他上阵、教不教他术式、
    让他领哪一部——**培养是玩出来的,不是菜单里点出来的**。
- **传承的东西**(骑砍式:门第延续,世界不重置):
  你的部曲老兵 · 武将班底(跟不跟他,看关系与威望) · 与朝廷的关系(打折继承) ·
  封地与商队(经营层) · **门第声望**(跨代累积)。
- **每个人都有自己的天赋上限**,魔力远不及主角(那是养了很久的)——
  **所以主角之死是真损失,不是换皮**;也可以选择做一个**全无魔力的普通指挥官**,
  靠指挥本事活下去(这条路必须真的走得通)。
- **引子留给玩家的行为**:夺回遗体厚葬 / 以此为由宣战 / 就此背叛国家——**不给选择框**。
- 接受不了,回档重打这场战役。

## 7. 力量锚点(平衡起点,待实测调整)

- 主角一战约 **8 发**,每发在密集阵中带走 **20–40 人** → 约 **200–350 人**;
- 当面之敌一路 1000–2000 人 → **一到两成**。对一个人骇人听闻,对一场会战远不足以定胜负。

**六条物理限制(皆为代价,非禁令)**
1. 术式载荷有限(战中不回复);
2. **占不住地**——飞行单位无法占领和守住一寸土地,步兵才能;
3. **溃可复聚**——你炸垮一部,一走他们就被收拢(现有机制);你必须留下,而你不能同时在三处;
4. **散阵即反制**——**逐兵模拟白送的**:一发落在密集阵带走三十人,落在散阵可能只有七八个。
   聪明的敌人会散开,而散开的骑兵冲不动、散开的步兵结不成线——
   **你重塑了战场,却没有赢下战场**;
5. **敌有反制**——对空弩阵、敌方术士、冥府那边更不讲道理的东西;
6. **用之伤神**——SAN 下滑 → 情报失真、幻影敌情。

## 8. 各方国策:让「魔法不是万能」有活的证据

| 势力 | 国策 | 表现 |
|---|---|---|
| 大酆朝廷 | **用而防之** | 术士入军籍、设监临;玩家的「超量」让**皇恩与猜忌同时飙升**,直接喂主帅信任轴 |
| 草原游牧 | **萨满之道** | 少而野;不炮击,擅天候 / 惊马 / 咒诅——打法完全两回事 |
| 东北藩镇 | **募而用之** | 花钱雇,无意识形态,谁给钱替谁打 |
| 邪教 / 冥府 | **其道即术** | 最多、最怪;打他们 SAN 掉得最狠 |
| 某镇 / 某国 | **禁术** | 视为亵渎,转而发展**反制学说**:对空弩阵、散阵行军、铁律不乱。 |

> **「禁术势力」是世界给玩家的活证据**:撞上他们,你的炮击收益腰斩——
> 魔法不是王,这句话由世界本身说出来,不由数值面板说出来。

## 9. 分层路线与开工建议

| 层 | 内容 | 归属 |
|---|---|---|
| **先做** | 术士队兵种 + 主角亲征(含完整代价链路) | 战术层 L0 扩展 |
| **紧接** | 主帅坠地实时争夺 + **威望轴** + 治军方针 | 战术层 + 一条新元状态 |
| 之后 | 被俘 / 赎回 / 部队 AI 托管 | L2–L3 |
| 之后 | 传承与天赋上限 | 生涯层 |
| 之后 | 各方国策与魔导军备 | L3 势力模拟 |

**理由**:平衡这种东西只能靠打出来。先把「很强但翻不了盘」在黑松岭和野地遭遇战里
反复验证成真手感,再往上叠政治与生涯——**每层可玩、可收档**(宏观构想 §8 铁律)。

## 10. 与现有系统的咬合清单(实现时对表)

- **SAN**:施术耗神 → 已有 `SanFactor` 管线(回报误差 + 幻影敌情)直接可用;
- **万骨账 `Bones`**:已在记 → 直接作为**威望**的负向输入;
- **主帅信任 `Trust`**:已有 → 与威望构成背离的两轴;
- **请示求决 / 武将性格自处**:已有 → **这是亲征惩罚的执行者**,不需新写惩罚逻辑;
- **令骑可截杀**:已有物理 → 直接复用于**押送途中的拦截救主**;
- **旗鼓的军令泄露**:已有 → 同源逻辑用于「你在天上,全场都知道主帅在哪」;
- **逐兵模拟**:面杀伤对密集/散阵的收益差**自动成立**,散阵反制不需要额外规则;
- **`WorldParty`(大地图 NPC 队伍)**:已有容器 → 被俘期间你的部队托管其中;
- **兵形 50:1 显示**:术士队人少,需单列显示规则。
